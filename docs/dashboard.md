# 관제 대시보드 (WBS 5.5)

파이프라인이 내는 알람을 지도 위에 보여 준다.

담당: 박서연 / 상태: 동작 확인, 디자인 적용 (배경 지도 타일은 인터넷 필요)

## 쓰는 법

```bash
# 1) 대시보드 켜기 (파이프라인보다 먼저 켜 두어도 된다)
python src/dashboard/server.py --out results/pipeline --geo-dir data/geo_jagok --frames sim/frames_scenario \
    --report 37.468913 127.10057

# 2) 다른 창에서 파이프라인 실행
python src/pipeline/run.py --frames 사진폴더 --weights best.pt \
    --geo-dir data/geo_jagok --sim-terrain sim/terrain_jagok3d.json --vlm fake --interval 1

# 3) 브라우저에서 http://localhost:8800
```

외부 패키지 없이 돈다. 지도 라이브러리(Leaflet 1.9.4, BSD-2)는 `src/dashboard/vendor/`에 들어 있다. 글꼴과 배경 지도 타일은 인터넷에서 받는다.
화면은 1초마다 `alerts/` 폴더를 다시 읽는다.

| 옵션 | 내용 |
|---|---|
| `--out` | 파이프라인 출력 폴더 (`alerts/`, `detections/`가 있는 곳) |
| `--geo-dir` | `landuse_5179.geojson`이 있으면 용도지역 폴리곤을 지도에 그린다 |
| `--frames` | 탐지 JSON에 사진 파일 이름만 있을 때 사진을 찾을 폴더 |
| `--port` | 기본 8800 |
| `--center 위도 경도` | 알람이 없을 때 지도 가운데. 기본은 자곡동 `37.4710 127.1034` |
| `--site-name "이름"` | 화면 왼쪽 위 지역 이름. 기본은 `자곡동 · 서울 강남구` |
| `--report 위도 경도` | 신고 지점. 지도에 핀과 수색 반경을 그리고, 알람이 신고 지점에서 몇 m인지 보여 준다 |
| `--report-radius m` | 신고 지점 둘레 수색 반경. 기본 600 (`docs/simulator.md` 의 `vwSearch` 와 같음) |

시연 지역은 11/07부터 서울 강남구 자곡동이다(`docs/demo_area.md`). 강릉 모래고개입구 자료로 볼 때는
`--geo-dir data/geo_moraegogae --center 37.736790 128.906239 --site-name "모래고개입구 · 강원 강릉시 노암동"`.

배경 지도는 기본이 OpenStreetMap이다. 환경변수 `VWORLD_KEY`가 있으면 V-World 위성과 일반 지도를
고를 수 있다. 인증키에 `http://localhost`가 등록되어 있어야 한다.

## 화면

밝은 브리핑 보드 테마(11/15 개편). 시안은 Figma "엣지아이 관제 대시보드"의 `시안 A-3`.
글꼴은 Noto Sans KR(한글)과 Barlow(숫자, 둘 다 SIL OFL). 구글 폰트에서 불러오고, 인터넷이 없으면 시스템 글꼴(맑은 고딕 등)로 뜬다.

- 왼쪽
  - 확정 알람 수(크게), 영상 검증 통과 / 헛탐지 의심 / 검증 중 개수
  - 판정별 개수(확정·모호·미확정)와 점 게이지. 누르면 그 판정만 거르고, 한 번 더 누르면 전체
  - 타임라인(최신이 위): 시각, 번호, 판정, 요약 한 줄(용도 · 연기 색 · 반경), 위험도, 영상 검증
  - 탐지·지리 조회 시간(중앙값), VLM 대기열
- 지도 (오른쪽)
  - 알람 위치와 오차 반경 원. 판정별 색과 선(확정 빨강 실선, 모호 주황 파선, 미확정 회색 점선)
  - 드론 위치(기수 방향 화살표)와 시선 점선, 용도지역 폴리곤, 새 알람 따라가기: 위쪽 버튼으로 켜고 끔
  - 배경 지도: 일반(OSM을 옅게) / 위성(V-World, `VWORLD_KEY`가 있을 때)
- 선택한 알람 시트 (지도 아래에 뜸)
  - 탐지 사진과 연기 박스·점수, 번호, 판정, 위험도, 영상 검증, 시각·드론 고도·기수
  - 위험도 근거 한 줄, 설명(없으면 "설명 생성 중 · N초 경과")
  - 오차 반경, 반경 안 건물, 주변 경사, 설명까지(설명 전에는 알람까지) 걸린 시간
  - 용도 비율 막대와 판정 기준
- 폭이 좁은 화면(휴대폰)에서는 왼쪽 → 지도 → 시트 순서로 쌓인다

### 신고 지점

`--report` 를 주면 지도에 "신고 지점" 핀과 수색 반경(점선 원)을 그린다. 알람이 없을 때는 신고 지점을
가운데로 보여 주고, 첫 화면 범위에도 넣는다. 시트에는 "신고 지점에서 N m" 가 붙는다. 위쪽 버튼으로 켜고 끈다.

### 알람 갱신

같은 `alert_id` 의 판정, 반경, 위치가 바뀌면 갱신으로 센다(설명이 붙는 것은 세지 않는다).

- 타임라인 항목에 "갱신 N", 시트에 "미확정 184m → 모호 61m → 확정 26m · 마지막 시각" (최근 4개)
- 선택한 알람은 지도에 갱신 전 위치들을 옅은 점과 점선으로 잇는다
- 갱신되면 항목이 잠깐 노랗게 빛나고, "새 알람 따라가기"가 켜져 있으면 지도가 새 위치로 간다
- 파이프라인이 같은 사건을 더 좁은 반경으로 다시 짚으면 같은 알람을 고쳐 다시 낸다(`docs/pipeline.md` "알람 갱신")
- 기록은 파이프라인의 `alerts.jsonl`(알람을 낼 때마다 한 줄)에서 만든다. 이 파일이 없는 경우
  (`tools/replay_alerts.py`, `tools/live_estimate.py` 처럼 `alerts/` 만 덮어쓸 때)는 화면이 열려 있는 동안
  1초마다 본 변화를 쌓는다. 그래서 이때는 화면을 먼저 켜 두어야 처음부터 기록된다
- 갱신 기록은 알람 형식에 칸을 두지 않고 `alerts.jsonl`로 만든다

### 영상 검증 (11/19 회의 뒤 알람 v0.4)

검증기가 탐지 조각에서 본 결과(`verifier`)를 쓴다. 사진 일부만 보고 답한 설명용 `observed`보다 정확하다.

| 표시 | 조건 |
|---|---|
| 영상 검증 통과 | `verifier.passed` 가 true |
| 헛탐지 의심 | `verifier.passed` 가 false (사진을 흐리게 보여 줌) |
| 검증 중 | `verifier` 가 아직 null 이고 설명도 없음 |
| (표시 없음) | 검증기를 끄고 돌림 (`--no-verify`, `--vlm none`) |

칩에 마우스를 올리면 P(연기)가 보인다. 예전 알람(v0.3)은 `observed.smoke_present` 로 대신한다.

### 위험도

알람의 `risk: {level, reason}` 을 그대로 보여 준다(높음 ●●● / 보통 ●●○ / 낮음 / 확인 필요 ●○○).
규칙은 `src/vlm/risk.py` 하나뿐이다(`docs/schema.md` "risk, verifier"). 설명 문장의 "위험도 …"도 같은 값이다.
`risk` 가 없는 예전 알람만 `index.html` 의 `riskOf()` 임시 규칙으로 표시하고 "(임시 규칙)"을 붙인다.

### 시트 지표

오차 반경, 반경 안 건물, 가장 가까운 건물(`evidence.nearest_building_m`), 주변 경사. 알람·설명까지 걸린 시간은
시트 위 한 줄(시각 · 드론 · 신고 지점에서 거리 옆)로 옮겼다.

## 확인한 것 (11/15)

자곡동 신고 시나리오(`sim/frames_scenario` 38장, `data/geo_jagok`, `--sim-terrain`, `--report 37.468913 127.10057`)

- 화면을 켜 둔 채 파이프라인을 돌리니 a-0001 이 "미확정 276.8m" 로 뜬 뒤 1초마다 갱신되어
  "확정 31.1m · 갱신 6" 이 됐다. 시트에 갱신 기록, 지도에 이전 위치 자취, 신고 지점에서 거리(약 290m)
- 갱신될 때마다 설명이 "설명 생성 중" 으로 바뀌었다가 새 위치의 문장으로 채워졌다
- 브라우저 콘솔 오류 없음

그 밖 (아래는 시나리오 자료가 오기 전 시험)

탐지 가중치(best.pt)와 시뮬레이터 프레임 4장, fake VLM 2초, 후보 검증기 켬, 프레임 간격 1초

- 자곡동 기본값, `--sim-terrain sim/terrain_jagok3d.json`, `--report`: 알람 3개, 설명 3/3, 형식 검사 3/3,
  지형 격자(20m 간격)가 좌표 변환과 경사 조회에 쓰임, 시트에 "신고 지점에서 N m"
  (자곡동 지리 자료가 아직 없어 강릉 프레임과 용도지역을 자곡동 위치로 옮겨 시험했다. 오차 수치는 의미 없음)
- 강릉 자료(`--center`, `--site-name` 으로 되돌림): 알람 4개, 설명 4/4, 형식 검사 4/4
- 알람 갱신: 같은 a-0001 을 미확정 184m → 모호 61m → 확정 26m 로 덮어쓰니 "갱신 2", 갱신 기록, 지도 자취가 떴다.
  `alerts.jsonl` 로 만드는 기록은 설명만 붙은 줄을 갱신으로 세지 않았다
- 헛탐지 의심(`smoke_present: false`)과 검증 중(`description: null`) 표시
- 브라우저 콘솔 오류 없음 (배경 타일은 시험 환경에서 인터넷이 막혀 비어 있었다)
- 첫 프레임 탐지 시간에 모델 준비 시간(약 14초)이 붙던 것을 미리 한 번 돌려 없앴다(`detect.py`)

## 남은 것

- 알람 해제 표시는 향후 과제 (갱신은 11/15에 넣음)
- 알람 항목의 "반경 내 주거 건물 수"는 지금 전체 건물 수다 (건물 자료에 용도 없음)
- 위험도는 임시 규칙이다. 팀 규칙이 정해지면 `riskOf()` 를 바꾸거나 파이프라인이 `risk` 를 채운다 (schema v0.4)
- 자곡동 실제 자료(`data/geo_jagok`, 시나리오 프레임)로 다시 확인
- 시연용 녹화 영상으로 실제 속도 확인 (8.2)
