# 관제 대시보드 (WBS 5.5)

파이프라인이 내는 알람을 지도 위에 보여 준다.

담당: 박서연 / 상태: 동작 확인, 디자인 적용 (배경 지도 타일은 인터넷 필요)

## 쓰는 법

```bash
# 1) 대시보드 켜기 (파이프라인보다 먼저 켜 두어도 된다)
python src/dashboard/server.py --out results/pipeline --geo-dir data/geo_moraegogae

# 2) 다른 창에서 파이프라인 실행
python src/pipeline/run.py --frames 사진폴더 --weights best.pt \
    --geo-dir data/geo_moraegogae --vlm fake --interval 1

# 3) 브라우저에서 http://localhost:8800
```

외부 패키지 없이 돈다. 지도 라이브러리(Leaflet 1.9.4, BSD-2)는 `src/dashboard/vendor/`에 들어 있다.
화면은 1초마다 `alerts/` 폴더를 다시 읽는다.

| 옵션 | 내용 |
|---|---|
| `--out` | 파이프라인 출력 폴더 (`alerts/`, `detections/`가 있는 곳) |
| `--geo-dir` | `landuse_5179.geojson`이 있으면 용도지역 폴리곤을 지도에 그린다 |
| `--frames` | 탐지 JSON에 사진 파일 이름만 있을 때 사진을 찾을 폴더 |
| `--port` | 기본 8800 |

배경 지도는 기본이 OpenStreetMap이다. 환경변수 `VWORLD_KEY`가 있으면 V-World 위성과 일반 지도를
고를 수 있다. 인증키에 `http://localhost`가 등록되어 있어야 한다.

## 화면

어두운 관제실 테마. 시안은 Claude Design 캔버스 "엣지아이 관제 대시보드"에 있다.

- 상단 바: 알람 수, 판정별 개수, 설명 대기 건수, 탐지·지리 조회 시간(중앙값), 실시간 표시, 새 알람 따라가기
- 지도
  - 알람 위치와 오차 반경 원. 판정별 색과 선(확정 빨강 실선, 모호 주황 파선, 미확정 회색 점선)
  - 선택한 알람은 말풍선(번호, 판정, 1순위 용도, 반경)과 테두리로 강조
  - 드론 위치(기수 방향 화살표)와 알람까지 잇는 점선. 켜고 끌 수 있음
  - 용도지역 폴리곤. 켜고 끌 수 있음
  - 배경 지도: 일반(OSM을 어둡게) / 위성(V-World, `VWORLD_KEY`가 있을 때)
  - 범례, 축척
- 알람 목록 (최신이 위, 판정으로 거르기)
  - 선택한 알람은 펼쳐서 보여 준다: 탐지 사진과 연기 박스·점수, 드론 고도·기수, 설명,
    지표 4칸(오차 반경, 반경 안 건물, 주변 경사, 1순위 비율), 용도 비율 막대, 판정 기준,
    "탐지 → 알람 → 설명" 걸린 시간
  - 나머지는 한 줄로 접는다
  - 설명이 아직 없으면 "설명 생성 중… N초 경과"
  - VLM이 연기를 보지 못했다고 답하면 "헛탐지 가능성" 표시
- 폭이 좁은 화면(휴대폰)에서는 지도 아래에 목록이 쌓인다

## 확인한 것 (11/1)

실제 자료(best.pt, 모래고개입구 지리 자료, 시뮬레이터 프레임 4장), fake VLM 6초, 프레임 간격 1초

- 알람이 나오는 대로 지도와 카드에 떴고, 설명이 붙으면 같은 카드가 "설명 생성 중"에서 문장으로 바뀌었다
- 알람 4개, 설명 4/4, 형식 검사 4/4
- 브라우저 콘솔 오류 없음 (배경 타일은 시험 환경에서 인터넷이 막혀 비어 있었다)

## 남은 것

- 알람 생명주기(갱신, 해제) 표시는 향후 과제
- 알람 항목의 "반경 내 주거 건물 수"는 지금 전체 건물 수다 (건물 자료에 용도 없음)
- 시연용 녹화 영상으로 실제 속도 확인 (8.2)
