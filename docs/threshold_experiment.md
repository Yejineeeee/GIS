# 판정 임계값 결정 실험

확정, 모호, 미확정을 가르는 기준값을 임의로 정하지 않고 실험으로 정한다. 이미지가
필요 없고 용도지역 폴리곤만 있으면 돌아간다.

담당: 이수진 / 상태: 예비 실험 완료, 본 실험 대기

예비 실험(300곳)은 내가(이예진) 임계값 실험이 가능한지 확인하려고 먼저 돌렸다.
본 실험은 시연 지역이 정해진 뒤 1,000곳으로 수진이가 다시 측정한다.

## 방법

1. 용도지역 폴리곤을 미터 좌표계로 바꾼다.
2. 정답 위치를 무작위로 뽑고 그 지점의 실제 용도를 기록한다.
3. 오차 반경 10m, 30m, 50m, 100m만큼 위치를 흔들어 추정 위치를 만든다.
4. 추정 위치 주변의 용도 비율을 두 방식으로 구한다.
   - 반경 안 여러 지점을 찍어 세는 방식
   - 원과 폴리곤의 교집합 면적으로 구하는 방식
5. 판정 규칙 두 가지에 임계값을 0.05 간격으로 넣어 확정 비율과 확정 정확도를 기록한다.
   - 최다 비율 기준: 1순위 용도의 비율이 기준 이상이면 확정
   - 1, 2순위 격차 기준: 1순위와 2순위의 차이가 기준 이상이면 확정

## 예비 결과 (300곳)

서울 강남 일대 용도지역, 정답 위치 300곳으로 돌린 결과다. 지역이 시연 지역과
다르고 지점 수도 적어 그대로 쓸 수 없다. 방법이 작동한다는 것까지만 보인다.

목표 정확도 95%를 만족하는 가장 낮은 임계값(최다 비율 기준, 면적 비율 방식)

| 오차 반경 | 임계값 | 확정 비율 |
|---|---|---|
| 10m | 0.40 | 100% |
| 30m | 0.55 | 98% |
| 50m | 0.65 | 91% |
| 100m | 0.70 | 76% |

- 오차 반경이 커질수록 같은 정확도를 지키려면 확정 판정 비율을 줄여야 한다.
- 지점을 찍어 세는 방식과 면적으로 구하는 방식의 결과 차이는 크지 않다.
- 1, 2순위 격차 기준은 반경 50m 이상에서 목표 99%에 도달하지 못했다.

결과 표는 `results/threshold_sim_result.csv`, 그림은 `results/chart_risk_coverage.png`와
`results/chart_rule_compare.png`에 있다.

## 주의

용도지역 폴리곤에는 지정 연도가 다른 이력이 겹쳐 있다. 그대로 면적을 더하면 같은
땅이 두 번 계산되어 1순위 비율이 0.5 부근으로 눌린다. 최신 지정 연도를 우선해
중복을 걷어낸 뒤 계산한다.

## 본 실험으로 넘기는 것

수진이가 맡는다. 3.4 지리 조회 모듈이 나오면 그걸로 돌린다.

| 항목 | 예비 | 본 실험 |
|---|---|---|
| 지역 | 서울 강남 | 시연 지역 (장현동 후보) |
| 지점 수 | 300 | 1,000 |
| 판정 규칙 | 최다 비율, 격차 두 가지 | 같음 |
| 반경 | 10, 30, 50, 100m | 같음 |

쓸 수 있는 것

- `tools/fetch_zoning.py` 용도지역 내려받기
- `tools/threshold_sim.py` 모의 실험. 폴리곤 파일과 지점 수를 인자로 받는다

```
python tools/fetch_zoning.py 최소경도 최소위도 최대경도 최대위도 zoning.geojson
python tools/threshold_sim.py zoning.geojson 1000 30
```

주의할 것

- 용도지역 폴리곤은 지정 연도가 다른 이력이 겹쳐 있다. 최신을 우선해 중복을
  걷어내지 않으면 1순위 비율이 0.5 부근으로 눌린다.
- 모호 판정 기준은 아직 실험으로 정하지 않았다. 확정 문턱만 정해져 있다.
