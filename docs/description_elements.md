# 설명 문장의 요소 포함률과 문장 늘리기

`docs/generation_methods.md` 의 요소 포함 45%, 회피 25건이 지금 파이프라인의 값인지 다시 셌고,
알람에 이미 있는 값을 문장에 더 담았다. 문장은 계속 규칙이 조립한다.

담당: 이예진 / 상태: 템플릿 수정 완료, 평가셋 v1(6.2 확정 전) 기준. 확정본이 들어오면 다시 센다

## 다시 센 이유

45% 는 방식 (iii)을 4.6 실험 설정으로 돌린 값이다. 그때는 VLM 이 연기가 없다고 답하면 문장이
"연기가 관측되지 않았다"로 끝났고, 회피 25건이 모두 그 경우였다. 지금은 연기 유무를 탐지와
후보 검증기가 정하고 문장은 "연기가 탐지되었다"로 시작한다. 같은 일이 생기지 않는다.

## 방법

`tools/element_coverage.py`. VLM 을 다시 돌리지 않고 `results/eval_method_iii.jsonl` 의 답을
그대로 쓴다. 채점은 `tools/score_descriptions.py` 의 `score_one` 을 그대로 부른다. 연기 사진 70장.

```
python tools/element_coverage.py --out results/element_coverage_v1.jsonl --sheet docs/description_sheet_v1.md
```

## 결과

| 문장 | 무엇 | 어디 | 위험 대상 | 불확실성 | 요소 포함 | 회피 | 판정 준수 | 과신 | 평균 길이 |
|---|---|---|---|---|---|---|---|---|---|
| 4.6 설정 (문서의 45%) | 0 | 36 | 45 | 45 | 45% | 25 | 70/70 | 0/29 | - |
| 짧은 문장 (고치기 전) | 0 | 56 | 70 | 70 | 70% | 0 | 70/70 | 0/29 | 67자 |
| 늘린 문장 (지금) | 0 | 70 | 70 | 70 | 75% | 0 | 70/70 | 0/29 | 113자 |

- **지금 파이프라인의 요소 포함은 45% 가 아니다.** 고치기 전 문장으로도 70% 이고 회피는 없다
- **"무엇"이 0 인 것은 채점 기준 때문이다.** 채점기는 문장에 클래스 이름(흑색연기 등)이 있어야
  "무엇"으로 친다. 연기색을 쓰지 않기로 해서 문장은 "연기가 탐지되었다"다. 연기라고 말한 것을
  "무엇"으로 치면 짧은 문장 95%, 늘린 문장 100% 다
- **"어디"는 미확정 14장에서 빠졌었다.** 미확정이면 용도 이름을 쓰지 않기 때문이다. 좌표를 적어
  채웠다. 용도 이름은 여전히 쓰지 않는다
- 판정 준수와 과신은 그대로다. 더한 것이 모두 알람의 계산값이기 때문이다
- 문장을 만드는 시간은 0.01ms 로 무시할 수 있다

## 문장에 더한 것과 뺀 것

`src/vlm/templates.py` 의 `build(..., rich=True)` (기본). `rich=False` 는 고치기 전 문장이다.

| | 내용 | 값의 출처 |
|---|---|---|
| 더함 | 용도 비율: 자연녹지지역(64%) | `land_use[].ratio` |
| 더함 | 미확정일 때 좌표 | `position.lat`, `position.lon` |
| 더함 | 경사 | `evidence.terrain_slope_deg` |
| 더함 | 위험도와 근거 | `src/vlm/risk.py` (규칙 초안, `docs/vlm_situation.md`) |
| 더함 | 모호일 때 권고: 접근해 위치를 다시 확인할 것 | 판정 |
| 뺌 | VLM 이 답한 지형: 주변이 산림이다 | 검증하지 않은 답. "제1종일반주거지역에서 발생했다. 주변이 산림이다"처럼 어긋났다 |

예 (평가셋의 값)

```
확정    연기가 탐지되었다. 제1종일반주거지역(100%)에서 발생했다. 좌표 오차 반경은 30미터다.
        반경 안 건물은 5개, 경사는 2도다. 위험도 높음: 반경 안에 주거지나 건물이 있다.
모호    연기가 탐지되었다. 오차 반경 50미터 안이라 자연녹지지역(64%)과 제1종일반주거지역(36%) 중
        하나로 보인다. 반경 안 건물은 4개, 경사는 1도다. 위험도 높음: 반경 안에 주거지나 건물이
        있다. 접근해 위치를 다시 확인할 것.
미확정  연기가 탐지되었다. 좌표 오차 반경이 50미터여서 정확한 용도는 알 수 없다. 추정 위치는
        위도 37.7420, 경도 128.8941 부근이다. 반경 안 건물은 7개, 경사는 3도다. 위험도 확인 필요:
        위치가 불확실하다. 접근해서 다시 판정한다.
```

## 알람에 값이 생기면 문장에 들어가는 것

문장 쪽 자리는 만들어 두었다. 값이 없으면 그 구절이 빠진다.

| 구절 | 필요한 값 | 고칠 곳 |
|---|---|---|
| 연기가 탐지되었다(영상 검증 통과) | `verifier.passed` | 알람 (`run.py`, `alert.py`, `docs/schema.md`) |
| 가장 가까운 건물까지 약 40미터 | `evidence.nearest_building_m` | 지리 조회 (`src/geo/query.py`) |

칸 이름은 제안이다. 담당자와 정한 이름으로 바꾼다.

넣지 않은 것: 주거 건물 수(건물 자료에 용도 정보가 없다), 굴뚝으로 보임(공장 지대 밖에서
15장 중 1장만 맞다), 판정이 바뀐 이력(알람에 이전 값이 없다).

## 평가지

`docs/description_sheet_v1.md`. 짧은 문장과 늘린 문장을 10건(확정 4, 모호 3, 미확정 3) 나란히
놓았다. 어느 쪽이 어느 것인지는 섞어 두고 끝에 적었다. 사람 평가가 하나도 없어서 만들었다.

## 한계

- 위험도는 규칙 초안이고 정답과 맞춰 본 것이 아니다. 평가셋 연기 70장에서 높음 48, 확인 필요
  14, 보통 8 로 높음에 몰린다. 평가셋의 가상 위치가 산림과 주거지 경계에 놓여 있기 때문이다
- 요소 포함은 낱말이 있는지로 센다. 문장이 판단에 도움이 되는지는 평가지로 따로 봐야 한다
- 문장이 67자에서 113자로 길어졌다. 대시보드 카드에 들어가는지 확인이 필요하다
- 평가셋 v1 이고 장소가 두 곳이다
