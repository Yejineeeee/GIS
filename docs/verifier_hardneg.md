# 탐지기 학습용 hard negative로 검증기에 선형 분류기 붙이기 (WBS 4.7 ③ 보충)

후보 검증기(Qwen2.5-VL-3B 4비트, P(예) ≥ 0.7)는 학습 없이 질문만으로 쓴다. 그래서 안개연무를
하나도 못 거르고(0/8) 굴뚝연기도 절반 넘게 통과시킨다(`docs/verifier_margin.md`). 탐지기를 학습할 때
쓴 AI Hub 71330의 NegativeDB 사진(구름, 안개연무, 굴뚝연기)을 검증기에 보여 주면 나아지는지 쟀다.

담당: 이예진 / 상태: 측정 완료(11/26). 파이프라인은 아직 바꾸지 않았다

## 왜 선형 분류기인가

- 노트북 GPU가 RTX 3050 4GB라 LoRA 미세조정은 메모리가 모자란다
- 평가셋 사진은 AI Hub 데이터라 클라우드로 보낼 수 없다
- 그래서 VLM은 그대로 두고, 검증기가 답을 내기 직전의 은닉 상태(마지막 토큰)를 뽑아
  로지스틱 회귀만 학습했다. 추가 비용은 행렬곱 한 번이라 검증 시간은 그대로다

## 방법

`tools/hardneg_probe.py`

1. **prep**: 탐지기 학습/검증 사진(`data/yolo_1260`)에 지금 탐지기를 돌려 조각을 만든다.
   연기 사진은 conf 0.05, NegativeDB 사진은 탐지기가 이미 잘 걸러서 conf 0.001로 낮춰 조각을 모았다.
   박스가 정답 폴리곤과 IoU 0.1 이상이거나 중심이 폴리곤 박스 안이면 연기로 본다.
   평가셋의 장소와 150장 세트의 영상은 뺐다
2. **feats**: 조각마다 검증기와 같은 질문을 넣고 마지막 층과 가운데 층의 은닉 상태를 저장한다
3. **eval / thr**: 표준화 후 클래스 균형 L2 로지스틱 회귀(torch LBFGS)를 학습한다

| 학습 조각 | 수 |
|---|---|
| 연기 (전체 2,264개 중 1,000개 추출) | 1,000 |
| 연기 사진 속 다른 곳 (백색회색 320, 흑색 129) | 449 |
| 안개연무 | 220 |
| 구름 | 186 |
| 굴뚝연기 | 170 |
| 합계 | 2,025 |

시험은 검증기 실험과 같은 두 세트를 썼다.

- 평가셋 실제 사진 100장: 탐지 177개(연기 131, 헛탐지 46). 안개연무는 없다
- 장소를 섞은 150장: 탐지 165개(연기 135, 헛탐지 30). 안개연무 8개가 여기에만 있다

## 결과

마지막 층, C = 0.01, 문턱 0.5. 클래스 균형으로 학습한 로지스틱 회귀의 기본 문턱이라
시험셋을 보고 고른 값은 아니다.

| | 지금 검증기 | 분류기 | 둘 다 통과해야 남김 |
|---|---|---|---|
| **평가셋** AUC | 0.916 | **0.979** | |
| 연기 남김 | 127/131 | 126/131 | 123/131 |
| 헛탐지 거름 | 41/46 | 39/46 | **43/46** |
| 　굴뚝연기 | 2/6 | 4/6 | 4/6 |
| 　연기 사진 속 다른 곳 | 39/40 | 35/40 | 39/40 |
| **150장** AUC | 0.738 | **0.923** | |
| 연기 남김 | 121/135 | 121/135 | 119/135 |
| 헛탐지 거름 | 14/30 | 22/30 | **23/30** |
| 　굴뚝연기 | 3/9 | 5/9 | 5/9 |
| 　안개연무 | 0/8 | **7/8** | 7/8 |
| 　연기 사진 속 다른 곳 | 11/13 | 10/13 | 11/13 |

- 순위를 매기는 능력(AUC)은 두 세트 모두 크게 오른다. 150장에서 0.74 → 0.92
- 안개연무를 0/8에서 7/8까지 거르고, 굴뚝연기도 평가셋 2/6 → 4/6, 150장 3/9 → 5/9로 는다
- 대신 분류기 혼자 쓰면 연기 사진 속 다른 곳(흰 하늘, 그늘 등)을 지금보다 덜 거른다(평가셋 39 → 35).
  학습 조각에 이런 종류가 적었던 탓으로 본다
- 두 검사를 다 통과해야 남기면 헛탐지 거름은 둘 중 가장 좋고(평가셋 43/46, 150장 23/30),
  연기를 버리는 수는 평가셋 4개 → 8개, 150장 14개 → 16개로 는다

### 다른 설정

| 설정 | 평가셋 AUC | 150장 AUC | 비고 |
|---|---|---|---|
| 마지막 층 C=0.01 | 0.979 | 0.923 | 위 표 |
| 마지막 층 C=0.1 / 1.0 | 0.957 / 0.923 | 0.909 / 0.889 | 규제를 약하게 하면 나빠진다 |
| 가운데 층 C=0.01 | 0.965 | 0.926 | 문턱 0.5에서 평가셋 굴뚝 2/6, 다른 곳 34/40 |
| 가운데 층 C=0.1 / 1.0 | 0.910 / 0.873 | 0.918 / 0.900 | |

- 지금 검증기 문턱 0.7을 그대로 쓰면 분류기는 평가셋 연기를 114/131만 남긴다. 점수 척도가 달라서다
- 학습 조각에서 "지금 검증기와 같은 비율로 연기를 남기는" 문턱(5겹 교차검증, 장소별로 나눔)도 시도했다.
  학습 조각은 conf가 낮은 탐지까지 섞여서 지금 검증기도 연기를 82%만 남기고, 그래서 문턱이 0.25까지
  내려가 헛탐지를 30/46만 걸렀다. 학습 조각과 시험 조각의 분포가 달라 이 방식은 쓰지 않았다
- 참고로 평가셋에서 연기를 127개 남기는 문턱을 직접 찾으면 0.49, 150장에서 121개 남기는 문턱은 0.51이라
  기본값 0.5와 거의 같다

결과 파일: `results/verifier_hardneg_tau07.json`(문턱 0.7), `results/verifier_hardneg_thr.json`(학습 조각 기준 문턱),
`results/verifier_hardneg_tau05.json`(문턱 0.5, 둘 다 통과)

## 주의할 점

- **150장 세트는 학습 사진과 장소가 겹친다.** 이 세트의 사진은 학습 데이터의 모든 장소를 포함해서
  장소로 빼면 학습 사진이 남지 않았다. 그래서 같은 영상만 뺐다. 안개연무 7/8은 같은 장소의 다른 영상을
  본 결과라 실제보다 좋게 나왔을 수 있다. 평가셋은 장소까지 뺐다
- 안개연무는 150장 세트의 8개뿐이다. 평가셋에는 없다
- 층과 C는 시험 결과 6개를 보고 골랐다. 문턱은 고르지 않았지만 설정 선택에서 약간 낙관적일 수 있다
- 시험 조각 수가 적어서(헛탐지 46개, 30개) 한두 개 차이는 우연일 수 있다

## 결론

- 성공 기준("안개연무나 굴뚝 구분이 늘면서 진짜 연기를 버리는 수가 크게 늘지 않을 것")은
  분류기 단독으로는 충족한다. 평가셋 연기 남김 127 → 126, 굴뚝 2/6 → 4/6, 150장 안개연무 0/8 → 7/8
- 다만 평가셋 전체 헛탐지 거름은 41 → 39로 오히려 줄어서, 지금 검증기를 바로 대체하지는 않는다
- 파이프라인에 넣는다면 "둘 다 통과해야 남김"이 헛탐지를 가장 잘 거른다. 연기를 4개 더 버리는 대가를
  받아들일지는 팀이 정한다
- 학습 없는 검증기의 약점(안개연무)이 데이터만으로 상당히 메워진다는 점은 발표의 한계/향후 과제에
  "선형 분류기로 안개연무 7/8, 큰 하드웨어에서는 LoRA로 확장"으로 쓸 수 있다
