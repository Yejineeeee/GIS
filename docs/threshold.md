# 판정 임계값 모의 실험 (WBS 3.5)

오차 반경이 주어졌을 때, 반경 안 용도 비율이 얼마 이상이면 "확정"으로 판정해도 되는지 정한다.

담당: 이수진 / 상태: 검토 요청

## 방법

- 코드: `python3 tools/threshold_main.py <landuse_5179.geojson> <출력 폴더>` (시드 42, 외부 패키지 없음)
- 지역: 모래고개입구 범위(128.880 37.712 128.932 37.762), 용도지역 4종 레이어 12종 (`docs/landuse.md`)
- 정답 지점 1,000곳: 범위 가장자리 200m를 뺀 안쪽에서 고르게 뽑고, 그 지점의 용도를 정답으로 둔다
- 위치 오차: 반경 R(10, 30, 50, 100m) 안 아무 곳으로 정답 지점을 옮긴다 (원 안에 고르게)
- 조회: 옮긴 위치를 중심으로 반경 R 원 안의 용도 비율을 구한다 (용도지역을 5m 격자로 바꿔 계산)
- 판정 규칙 두 가지를 같은 조건에서 비교한다
  - 최다비율: 1순위 비율 ≥ 임계값이면 확정
  - 격차: 1순위 비율 − 2순위 비율 ≥ 임계값이면 확정
- 확정이 정답과 같은 비율(정확도)이 목표 90, 95, 99%를 넘는 가장 낮은 임계값을 고른다 (0.01 단위, 확정이 20곳 미만이면 고르지 않음)
- 다른 지역 검증: 서쪽 절반에서 임계값을 고르고, 동쪽 절반에 그대로 적용한 정확도를 같이 낸다

## 정리

1. 반경이 커질수록 같은 정확도를 지키는 데 높은 임계값이 필요하고, 확정할 수 있는 비율이 줄어든다.
   - 목표 95%: 임계값 0.00 → 0.57 → 0.72 → 0.80, 확정 비율 100% → 95.6% → 80.6% → 60.8% (10 → 100m)
   - 반경 100m에서는 정확도 99%를 지키려면 지점의 절반 이상(54%)을 확정하지 못한다
   - 임계값 하나로 모든 반경을 다룰 수 없으므로, 반경별 임계값 표를 쓴다
2. 두 규칙의 차이는 작다. 같은 목표에서 확정 비율 차이가 1.3%p 이내다.
   - 1순위 비율만 보면 되는 최다비율 규칙이 설명하기 쉬워 기본으로 제안한다
3. 서쪽에서 고른 임계값을 동쪽에 적용하면 정확도가 목표보다 0.3~2.7%p 낮게 나온다 (반경 50, 100m 기준)
   - 임계값이 그 지역에 맞춰져 있다는 뜻이다. 다른 지역에 쓸 때는 목표보다 한 단계 높은 임계값(예: 95% 목표면 99% 임계값)을 쓰는 것이 안전하다

## 한계

- 정답 지점을 범위 안에서 고르게 뽑아, 녹지 비율이 높은 지역 특성이 그대로 반영된다
- 위치 오차를 반경 안에 고르게 주었다. 실제 오차 분포(가운데에 몰리는지 등)는 측정하지 못했다
- "다른 지역"은 같은 범위의 동쪽 절반이다. 완전히 다른 지역 검증은 아니다
- 용도지역을 5m 격자로 바꿔 계산해 경계에서 수 m 차이가 날 수 있다
- 용도지역은 법적 구역이라 실제 토지 이용과 다를 수 있다 (제안서 데이터 한계)
