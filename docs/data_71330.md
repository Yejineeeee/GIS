# AI Hub 71330 라벨 확인

학습에 쓸 수 있는 실제 규모와 위치 정보 보유 여부를 확인한다. 이 숫자가 학습 계획과
평가셋 구성의 기준이 된다.

담당: 이수진 / 상태: 확인 전

## 절차

1. 데이터 신청 승인 여부를 확인한다.
2. 검증용 라벨링데이터(약 160MB)만 받아 압축을 푼다. 원천데이터는 받지 않는다.
3. 라벨 폴더를 대상으로 통계를 낸다.

```bash
python tools/count_labels.py "라벨 폴더 경로"
```

## 결과

| 항목 | 값 |
|---|---|
| 전체 라벨 수 | |
| 드론 촬영분 수 | |
| 드론 촬영분 중 GPS가 있는 비율 | |
| 드론 촬영분 중 고도가 있는 비율 | |
| 흑색연기 이미지 수 | |
| 백색과 회색연기 이미지 수 | |
| 화염 이미지 수 | |
| 촬영 장소 상위 3곳 | |

## 볼 때 기준

- 드론 촬영분 수가 학습에 쓸 수 있는 실제 규모다.
- GPS 비율이 낮으면 평가셋에서 위치를 가상으로 배치하고 그 사실을 표에 남긴다.
- 클래스별 장수는 대상을 연기로 한정한 근거가 된다.
- 프레임이 같은 영상에서 나온 경우가 많으므로 장수보다 촬영 건수가 다양한지를 본다.
- 촬영 장소 분포는 시연 지역을 정하는 근거가 된다. 촬영이 많은 지역을 고르면 지리
  결합 실험과 데이터가 같은 지역에서 이루어진다.
