# 경량 VLM 후보 비교

후보를 문서 기준으로 먼저 걸러낸 뒤 두 개만 실제로 돌려 보고 하나를 고른다. 모델은
추가 학습 없이 사용하고, 부족한 부분은 입력 설계로 보완한다.

담당: 이예진 / 상태: 조사 중

|---|---|---|---|---|---|---|

## 실측 비교

기준 환경에서 같은 이미지와 같은 질문으로 비교한다.

| 모델 | 메모리 | 이미지 1장 처리 시간 | 틀린 내용 수 | 형식 준수 |
|---|---|---|---|---|
| Qwen2.5-VL-3B (nf4 이중 양자화) | 적재 후 4.14GB / 최대 7.09GB | 180.7초 (첫 토큰 51.4초) | (확인 중) | 스키마 18/18, 일관성 18/18 |

측정 조건: 박서연 노트북 WSL2 (CPU 4코어, 메모리 8GB, 스왑 0, GPU 없음), 2026-10-17.
AI Hub 71330 val 6장(흑색연기 2, 백색회색연기 2, 구름 1, 굴뚝연기 1) x 3회, 워밍업 1회 제외, 중앙값.
입력 1024x576, 질문·스키마·형식 강제는 run_structured.py와 동일. compute float32 (GPU 측정은 float16).
참고: GPU 측정값 가중치 1.90GB, 최대 VRAM 2.19GB.

## 선정 기준

1. 기준 환경에서 실행되는가
2. 정해진 질문에 형식을 지켜 답하는가
3. 이미지에 없는 내용을 지어내지 않는가
4. 한국어 출력이 읽을 만한가. 어려우면 영어로 받고 문장은 템플릿으로 만든다
