# 위험도 평가셋: 실제 발화 위치로 매긴 위험도를 정답으로 규칙 채점

11/21 교수님 답변("위험도 성능을 보이려면 평가셋을 새로 구성해야 한다")에 따라, 정답 위치를 아는
시뮬레이션으로 위험도 평가셋을 만들고 위험도 규칙(`src/vlm/risk.py`)을 채점했다.

담당: 이예진 / 상태: 측정 완료(11/26)

## 정답과 예측

**정답**: 실제 발화점에서 50m 안에 건물이 있거나 주거지역이 걸리면 높음, 아니면 보통.
50m는 국립산림과학원 공동 연구가 산불 피해 관리 대상으로 제안한 산림 인접 시설 거리(30~50m)의 큰 값이다
(규칙 근거 문서와 같은 근거). 30m와 100m(산림재난방지법의 산림인접지역)도 같이 봤다.

**예측**: 파이프라인이 아는 값만 쓴다.

| 방식 | 내용 |
|---|---|
| 반경 규칙 (지금 파이프라인) | 추정 위치와 오차 반경으로 용도지역·건물을 조회하고 위치 판정을 한 뒤 `risk.assess`. 미확정이면 "확인 필요" |
| 한 점 조회 (기준선) | 추정 위치에서 정답과 같은 50m 로 조회. 위치 오차를 무시하고 항상 높음/보통을 낸다 |

불꽃, 굴뚝, 검증기 결과는 넣지 않았다. 위치와 공간정보로 정하는 부분만 채점한다.

## 사례

`tools/risk_eval.py`. 만드는 법은 `tools/verdict_sensitivity.py`를 따른다.

- 지역: 자곡동(건물 5,900동과 용도지역이 있는 범위). 강릉 시뮬레이션 지역에는 건물 자료가 없어서 옮겼다
- 발화점: 녹지지역(자연녹지, 생산녹지) 안에서 고르게 600곳. 산불 상황만 본다
- 드론: 자곡동 시뮬레이터 프레임 29장의 거리(200~800m)와 탐지 픽셀 오차, 자세 잡음 1배와 2배
- 지형: 시뮬레이터 지형 격자 하나로 정답과 계산을 모두 한다
- 추정 위치 오차 중앙값: 잡음 1배 28.0m, 2배 47.7m

## 결과 (정답 거리 50m)

| | 반경 규칙 | 한 점 조회 |
|---|---|---|
| **잡음 1배** (정답 높음 189, 보통 411) | | |
| 과소평가 (높음을 보통으로) | **12 (높음의 6.3%)** | 23 (12.2%) |
| 과대평가 (보통을 높음으로) | **24 (보통의 5.8%)** | 53 (12.9%) |
| 확인 필요 | 232 (38.7%) | 0 |
| 판단한 것 중 정확도 | 90.2% | 87.3% |
| **잡음 2배** (정답 높음 189, 보통 411) | | |
| 과소평가 | **21 (11.1%)** | 38 (20.1%) |
| 과대평가 | **29 (7.1%)** | 66 (16.1%) |
| 확인 필요 | 238 (39.7%) | 0 |
| 판단한 것 중 정확도 | 86.2% | 82.7% |

혼동행렬 (잡음 1배, 행 = 정답, 열 = 예측)

| | 높음 | 보통 | 확인 필요 |
|---|---|---|---|
| 반경 규칙, 정답 높음 | 107 | 12 | 70 |
| 반경 규칙, 정답 보통 | 24 | 225 | 162 |
| 한 점 조회, 정답 높음 | 166 | 23 | 0 |
| 한 점 조회, 정답 보통 | 53 | 358 | 0 |

- 가장 위험한 실수인 과소평가가 12.2% → 6.3%로 절반이 된다. 잡음 2배에서도 20.1% → 11.1%
- 대신 600곳 중 39%를 "확인 필요"로 넘긴다. 모두 위치 판정이 미확정인 사례다

### 이득은 어디서 오나

반경 규칙이 판단한 368곳만 놓고 한 점 조회와 견주면(잡음 1배):

| 같은 368곳 | 과소평가 | 과대평가 |
|---|---|---|
| 반경 규칙 | 12 | 24 |
| 한 점 조회 | 11 | 12 |

- **판단한 사례끼리는 한 점 조회보다 낫지 않다.** 과소평가는 같고, 과대평가는 2배다. 반경 안 어디든
  건물이 있으면 높음으로 보기 때문이다(보수적)
- **이득은 미루는 사례를 잘 고르는 데서 온다.** 확인 필요로 넘긴 232곳은 위치 오차 중앙값이 87.5m로,
  판단한 사례(18.9m)의 4.6배다. 이 232곳에서 한 점 조회는 53곳(23%)을 틀렸다
- 위치 판정에서 본 것과 같은 구조다. "확신이 없으면 단정하지 않는다"가 위험도에서도 성립한다

### 정답 거리를 바꾸면

| 정답 거리 | 과소평가율 반경 규칙 / 한 점 조회 | 과대평가율 반경 규칙 / 한 점 조회 |
|---|---|---|
| 30m | 2.4% / 23.2% | 11.8% / 12.6% |
| 50m | 6.3% / 12.2% | 5.8% / 12.9% |
| 100m | 21.9% / 7.2% | 0.4% / 12.8% |

(잡음 1배. 한 점 조회는 정답과 같은 거리로 조회하도록 맞췄다)

- 100m 기준에서는 반경 규칙의 과소평가가 더 크다. 확정 사례의 반경이 수십 m라서 100m 밖 건물을 보지 못한다.
  산림재난방지법의 100m 기준을 쓰려면 규칙에 "가장 가까운 건물까지 거리"(알람의 `nearest_building_m`)를
  넣어야 한다

## 주의할 점

- 정답도 같은 용도지역·건물 자료로 매긴다. 자료 자체의 오류는 들어가지 않는다
- 시뮬레이션 한 지역(자곡동), 정적 탐지 오차다. 실제 위험도 판단(바람, 연료, 경사)은 들어가지 않았다
- "확인 필요"를 실수로 세지 않았다. 드론을 더 가까이 보내라는 행동으로 이어지기 때문이다. 다만 관제
  부담은 39%만큼 생긴다
- 불꽃과 굴뚝 줄(규칙 1, 2, 4)은 이 평가에 없다. 불꽃과 굴뚝은 VLM 실험(`docs/vlm_base_pick.md`, `docs/chimney_demo.md`)에서 따로 다뤘다

결과 파일: `results/risk_eval_report.json`. 사례와 사례별 채점은 `runs/risk_eval/`

```
python tools/risk_eval.py --data-root <sim, data 가 있는 체크아웃> --out runs/risk_eval
```
