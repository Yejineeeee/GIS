# 좌표 변환 정리

사진 속 픽셀이 실제로 어디인지 계산하는 데 필요한 내용을 정리한다.

담당: 이수진 / 상태: 초안

## 픽셀 하나가 땅에서 몇 m인가

```
GSD(m/픽셀) = 센서 폭(mm) x 고도(m) / ( 초점거리(mm) x 이미지 가로 픽셀 수 )
```

센서 폭 13.2mm, 초점거리 8.8mm, 가로 5472픽셀인 카메라로 고도 100m에서 찍으면
다음과 같다.

```
GSD = 13.2 x 100 / (8.8 x 5472) = 약 0.0274 m/픽셀
촬영 범위 가로 = 0.0274 x 5472 = 약 150m
```

## 기울여 찍을 때 생기는 오차

카메라가 기울어져 있는데 수직으로 찍었다고 가정하면 실제 지점이 옆으로 밀린다.

```
밀리는 거리 = 고도 x tan(기울기)
```

고도 100m에서 기울기가 45도이면 약 100m가 밀린다. 여기에 드론 위치 자체의 오차
(일반 GNSS 기준 약 5m)가 더해진다.

| 상황 | 오차 원인 | 크기 |
|---|---|---|
| 촬영 각도를 아는 경우 | 드론 위치 오차 | 약 5m |
| 촬영 각도를 모르는 경우 | 수직 촬영으로 가정해 지점이 밀림 | 고도 x tan(기울기) |
| 합계 | 위 두 가지가 겹침 | 약 105~110m |

## 확인할 것

- 사용하는 데이터에 촬영 각도가 기록되어 있는지
- 고도가 해발 고도인지 지면으로부터의 높이인지
- 좌표계가 위도경도(EPSG:4326)인지 다른 체계인지
