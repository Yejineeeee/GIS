# 좌표 변환 정리

사진 속 픽셀이 실제로 어디인지 계산하는 데 필요한 내용을 정리한다.

담당: 이수진 / 상태: 초안

## 픽셀 하나가 땅에서 몇 m인가

```
GSD(m/픽셀) = 센서 폭(mm) x 고도(m) / ( 초점거리(mm) x 이미지 가로 픽셀 수 )
```

센서 폭 13.2mm, 초점거리 8.8mm, 가로 5472픽셀인 카메라로 고도 100m에서 찍으면
다음과 같다.

```
GSD = 13.2 x 100 / (8.8 x 5472) = 약 0.0274 m/픽셀
촬영 범위 가로 = 0.0274 x 5472 = 약 150m
```

## 기울여 찍을 때 생기는 오차

카메라가 기울어져 있는데 수직으로 찍었다고 가정하면 실제 지점이 옆으로 밀린다.

```
밀리는 거리 = 고도 x tan(기울기)
```

고도 100m에서 기울기가 45도이면 약 100m가 밀린다. 여기에 드론 위치 자체의 오차
(일반 GNSS 기준 약 5m)가 더해진다.

| 상황 | 오차 원인 | 크기 |
|---|---|---|
| 촬영 각도를 아는 경우 | 드론 위치 오차 | 약 5m |
| 촬영 각도를 모르는 경우 | 수직 촬영으로 가정해 지점이 밀림 | 고도 x tan(기울기) |
| 합계 | 위 두 가지가 겹침 | 약 105~110m |

## 고도별 계산

같은 카메라(센서 폭 13.2mm, 초점거리 8.8mm, 가로 5472픽셀)로 고도만 바꿔 계산했다.

```
고도 50m : GSD = 13.2 x 50 / (8.8 x 5472) = 약 0.0137 m/픽셀, 촬영 범위 가로 = 약 75m
고도 150m: GSD = 13.2 x 150 / (8.8 x 5472) = 약 0.0411 m/픽셀, 촬영 범위 가로 = 약 225m
```

| 고도 | GSD | 촬영 범위 가로 | 기울기 30도일 때 밀림 | 기울기 45도일 때 밀림 |
|---|---|---|---|---|
| 50m | 약 1.4cm | 약 75m | 약 29m | 약 50m |
| 100m | 약 2.7cm | 약 150m | 약 58m | 약 100m |
| 150m | 약 4.1cm | 약 225m | 약 87m | 약 150m |

높이 날수록 한 장에 넓게 찍히지만 픽셀 하나가 커져서 작은 연기는 덜 보인다.
촬영 각도를 모르면 밀리는 거리도 고도에 비례해 커진다. 고도 150m에서 45도로 찍었다면 약 150m에 드론 위치 오차 5m가 더해진다.

강릉 도엽 2개를 받았다. 파일은 저장소에 올리지 않는다.

| 항목 | 37804 (강릉) | 37808 (구정) |
|---|---|---|
| 형식 | ERDAS Imagine(.img), 실수형(float32) | 같음 |
| 해상도 | 90m (격자 한 칸 90m x 90m) | 90m |
| 크기 | 255 x 318칸 (약 23km x 29km) | 256 x 318칸 (약 23km x 29km) |
| 좌표계 | KGD2002 / Unified CS (UTM-K, EPSG:5179) | 같음 |
| 높이 범위 | 약 -3m ~ 991m | 약 -3m ~ 1,330m |
| 빈 값(NoData) | -9999 | -9999 |

- DEM 좌표는 미터 단위(EPSG:5179)라서, GPS 위도·경도(EPSG:4326)를 쓰려면 EPSG:5179로 변환해야 한다.
- 해상도가 90m라서 경사도는 넓은 지형의 경향 정도만 볼 수 있다.
- 71330 샘플 GPS(37.697849, 128.861917)와 시연 후보지(37.70001, 128.84467)는 모두 구정(37808) 도엽 안에 있다. 각 지점의 지면 높이는 약 147m, 약 138m다.

## 확인할 것

71330 데이터 설명(AI Hub), 드론 라벨 샘플 2개, DEM을 확인한 결과다.

- 사용하는 데이터에 촬영 각도가 기록되어 있는지
  → 기록되어 있지 않다. 데이터 설명과 샘플 모두 촬영 각도 항목이 없다.
  → 결론: "촬영 각도를 모르는 경우"로 보고, 수직 촬영으로 가정한 뒤 고도 x tan(기울기)만큼의 오차 반경을 함께 표시한다.
- 고도가 해발 고도인지 지면으로부터의 높이인지
  → 데이터 설명에는 "원시데이터 수집 고도"라고만 되어 있다. 샘플 GPS 지점의 지면 높이는 DEM 기준 약 147m인데 elevation 값은 93이다. 해발 고도라면 드론이 땅보다 낮은 셈이 된다.
  → 결론: elevation은 지면으로부터의 높이로 본다. 단, 샘플 1개 기준이고 DEM이 90m 격자라서 다른 샘플로 추가 확인이 필요하다.
- 좌표계가 위도경도(EPSG:4326)인지 다른 체계인지
  → gps는 "37.697849, 128.861917"처럼 위도·경도(도 단위)로 기록되어 있다. 측지계(WGS84 등)는 명시되어 있지 않다.
  → 결론: EPSG:4326(WGS84)으로 가정한다. DEM은 EPSG:5179이므로 GPS를 EPSG:5179로 변환해서 맞춘다.
- 추가로 발견한 것
  → 샘플의 address는 "강원도강릉시저동"인데, gps는 구정면 쪽(구정 37808 도엽)을 가리킨다. 주소와 GPS가 서로 다른 위치일 수 있어서, 위치 계산에는 address 대신 gps를 쓰고 다른 샘플도 확인한다.

참고: distance는 촬영 장비와 불 사이 거리 구간이다. 근거리(2.5~49m), 중거리(50~299m), 원거리(300m 이상). 샘플 값 "301"은 원거리에 해당한다.
