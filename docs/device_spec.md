# 현장 기기 기준 환경

현장 기기에서 동작하는지 확인하려면 기준 환경을 정하고 그 환경에서 재야 한다.
기준은 노트북 CPU 4코어, 메모리 8GB로 제한한 환경이며, 개발 환경(GPU) 결과는
참고로 함께 적는다.

담당: 박서연 / 상태: 작성 중

## 팀원 기기

| 사용자 | 종류 | CPU | 코어 | 메모리 | GPU | GPU 메모리 |
|---|---|---|---|---|---|---|
| | 노트북 | | | | | |
| | 노트북 | | | | | |
| | 스마트폰 | | | | | |

## 자원 제한 방법

아래 중 한 가지로 4코어, 8GB 환경을 만든다.

- Docker Desktop: `docker run --cpus=4 --memory=8g ...`
- WSL2: `%UserProfile%\.wslconfig`에 `[wsl2]`, `memory=8GB`, `processors=4`
- 윈도우에서 코어만 제한: 프로세스의 ProcessorAffinity 설정

## 측정 항목

| 항목 | 방법 |
|---|---|
| 메모리 사용량 | 모델을 올리고 이미지 한 장을 처리할 때 최대치 |
| 처리 시간 | 이미지 한 장을 넣고 결과가 나올 때까지 |
| 설명 표시 시간 | 탐지 시점부터 설명이 화면에 뜰 때까지 |
