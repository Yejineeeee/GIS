# 탐지 성능 평가 (WBS 6.4)

분할 모델(yolo11n-seg, 1,260장, 960px)의 탐지 성능을 평가셋으로 잰다.

담당: 이예진 / 상태: 평가셋 v1 로 1차 측정 완료. 6.2 확정본이 나오면 같은 도구로 다시 잰다

## 조건

- 평가셋 v1 100장(`docs/eval_set.md`): 연기 70장(모래고개입구, 흑색 30, 백색회색 40),
  오탐 유발 30장(장현동, 구름 15, 굴뚝연기 15). 학습 1,260장과 겹치지 않는다
- 정답은 71330 원본 라벨 폴리곤. 연기는 흑색연기, 백색/회색연기, 화염. 연기 사진 70장에
  연기 100개
- 모델 `runs/smoke_1260_960/weights/best.pt`, 입력 960px
- 마스크는 긴 변 960px 로 그려 IoU 를 잰다

```
python tools/eval_detect.py data/eval_100 runs/smoke_1260_960/weights/best.pt
```

- IoU 는 연기 사진마다 정답 전체와 탐지 전체의 IoU 평균이다
- 재현율(사진)은 연기와 겹치는 탐지가 하나라도 있는 사진의 수다
- 헛탐지는 연기와 전혀 겹치지 않는 탐지의 수다

분류별(conf 0.10): 흑색연기 27/30, 백색회색연기 34/40, 구름 알람 0/15, 굴뚝연기 알람 5/15.

## 학습 검증 세트와 비교

학습 검증 세트 252장에도 같은 도구를 돌려 기준을 맞췄다. 라벨은 71330 검증용 라벨
(VL)에서 1,260장에 해당하는 것만 골라 `tools/convert_labels.py` 로 다시 만들었다.

```
python tools/eval_detect.py data/val_252 runs/smoke_1260_960/weights/best.pt --out runs/eval_detect_val
```

다시 만든 라벨이 학습 때와 같은지 먼저 확인했다.

- 연기 사진 950장, 연기 객체 1,278개, 검증 252장(연기 190, 배경 62)으로 학습 기록과 같다
- 검증 세트 분할 mAP50 0.552 (학습 기록 0.559). 배치와 검증 설정 차이 정도다
- 배경 헛탐지가 모든 문턱에서 학습 기록과 같다(0.10 에서 7/62)
- 오탐 유발 사진 25장에는 백색/회색연기 폴리곤도 들어 있다. 학습 때처럼 배경으로 두었다

결과(conf 0.10)

| | IoU | 재현율(사진) | 연기 IoU 0.5 | 연기 IoU 0.25 | 연기 사진 한 장당 헛탐지 |
|---|---|---|---|---|---|
| 학습 검증 세트 252장 | 0.545 | 184/190 (97%) | 65% | 79% | 0.31 (58/190) |
| 평가셋 v1 100장 | 0.464 | 61/70 (87%) | 48% | 63% | 0.57 (40/70) |

| | 작은 연기 | 큰 연기 | 배경 헛탐지 |
|---|---|---|---|
| 학습 검증 세트 252장 | 49/53 (92%) | 135/137 (99%) | 7/62 (11%) |
| 평가셋 v1 100장 | 7/10 (70%) | 54/60 (90%) | 5/30 (17%) |

작은 연기는 연기 넓이 0.2% 미만이다(`docs/train_results.md` 와 같은 기준). 학습 기록의
54/56, 133/134 와 조금 다른 것은 세는 방식 차이다. 학습 기록은 사진 어디든 탐지가
있으면 찾은 것으로 셌고(이 방식이면 188/190), 이 도구는 연기와 겹친 탐지만 센다.
넓이 0.2% 근처 사진 3장이 계산 해상도에 따라 작은 쪽과 큰 쪽을 오간다.

같은 기준으로 봐도 평가셋에서 모두 낮다. IoU 0.08, 재현율 10%p, 작은 연기 22%p,
큰 연기 9%p가 떨어지고 연기 사진 안 헛탐지는 두 배 가깝다. 평가셋 연기는 학습에서
뺀 시연 지역(모래고개입구) 사진이라, 처음 보는 장소에서 성능이 떨어진 것으로 본다.
작은 연기는 10장뿐이라 비율이 크게 흔들릴 수 있다.

학습 검증 세트에서 놓친 6장 중 4장은 넓이 0.06% 이하였고 2장은 0.83%, 1.23% 였다.

## 놓친 것과 헛탐지

- 놓친 연기 사진 9장 중 4장은 연기 넓이가 0.25% 이하였다(0.01, 0.05, 0.15, 0.24%).
  나머지 5장은 0.6~13% 로 작지 않다
- 헛경보는 모두 굴뚝연기 사진이다. 구름 사진에서는 하나도 잡지 않았다. 학습 검증
  세트에서도 굴뚝연기가 헛탐지의 대부분이었다(5/20)
- 연기 사진 안 헛탐지 40개는 밭, 맨땅 등이다. 4.7 후보 검증기가 이 중 대부분을 거른다
  (`docs/vlm_base_pick.md`)

## 남은 것

- 6.2 확정본으로 다시 잰다
- 평가셋에서 크게 놓친 5장(넓이 0.6% 이상)을 직접 본다
