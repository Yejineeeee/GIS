# 검증기에 공개 미세조정 모델을 넣었을 때 (WBS 4.7 ③ 보충)

후보 검증기(`docs/vlm_base_pick.md` ③)는 Qwen2.5-VL-3B 원본에 "이 사진에 연기가 있는가"를
묻는다. 같은 원본을 산불 사진으로 미세조정한 공개 모델을 그 자리에 넣으면 나아지는지 쟀다.
직접 미세조정을 할지 정하기 전에 본 값이다.

담당: 이예진 / 상태: 측정 완료. 검증기는 바꾸지 않는다. 직접 미세조정도 하지 않는다

11/12, 평가셋 확정본 이전(탐지 173개: 연기 126, 헛탐지 47)으로 잰 값이다. 확정본(177개)으로 다시 재지 않았다.

## 왜 했나

- 다른 팀이 VLM 을 미세조정해 헛탐지를 줄였다. 우리도 해야 하는지 판단할 근거가 필요했다
- 직접 학습하기 전에, 이미 학습된 같은 크기의 공개 모델로 효과를 먼저 볼 수 있다

## 비교한 모델

| 이름 | 모델 | 비고 |
|---|---|---|
| 원본 | Qwen/Qwen2.5-VL-3B-Instruct | 지금 검증기 |
| 미세조정 | leon-se/ForestFireVLM-3B | 원본을 산불 드론 사진 1,196장으로 LoRA 미세조정. Apache-2.0. Seidel 외, Drones 2025, 9(5), 347 |

미세조정 모델은 독일과 크로아티아에서 찍은 사진으로, 영어 질문에 11개 항목을 JSON 으로
답하도록 학습했다. 4bit 로 개발 노트북 GPU 에 올라간다(최대 2.52GB, 원본과 같다).

## 방법

`tools/vlm_verify_ffvlm.py`. 탐지와 조각은 다시 만들지 않고 검증기 결과를 그대로 읽는다.

| 세트 | 출처 | 탐지 조각 | 연기 | 헛탐지 |
|---|---|---|---|---|
| 평가셋 100장 | `runs/verify_real` | 173 | 126 | 47 |
| 장소를 섞은 150장 | `runs/verify_situation` | 165 | 135 | 30 |

조각, 4bit nf4 이중 양자화, bf16, 448px 입력은 검증기와 같다. 저장돼 있던 검증기 값으로
AUC 를 다시 계산하면 0.897, 0.738 로 기존 문서의 0.90, 0.74 와 같다.

미세조정 모델은 영어 JSON 으로 학습했으므로 한국어 질문만 보면 불리하다. 그래서 두 모델
모두 세 가지로 물었다.

| 방식 | 질문 | 읽는 값 |
|---|---|---|
| 한국어 | 이 사진에 연기가 있는가. 예 또는 아니오로만 답하라 (검증기 그대로) | 첫 토큰 P(예)/(P(예)+P(아)) |
| 영어 | Is there smoke in this image? Answer only Yes or No. | P(Yes)/(P(Yes)+P(No)) |
| 학습 형식 | ForestFireVLM 저장소의 질문 그대로(11개 항목, JSON 으로 답하라) | 답의 첫 항목 `forest_fire_smoke_visible` 값 자리에서 P(Yes)/(P(Yes)+P(No)) |

학습 형식에서는 답을 끝까지 생성하지 않는다. 미세조정 모델이 실제로 내는 JSON 의 앞부분
(`{"forest_fire_smoke_visible": "`)을 붙여 주고 그다음 토큰의 확률만 읽는다.

```
python tools/vlm_verify_ffvlm.py --models ffvlm
python tools/vlm_verify_ffvlm.py --models base
python tools/vlm_verify_ffvlm.py --report-only
```

두 모델을 한 번에 돌리면 앞 모델이 GPU 메모리에 남아 뒤 모델이 6배쯤 느려진다. 따로 돌린다.
결과는 `runs/verify_ffvlm/scores.jsonl` 에 조각마다 한 줄씩 있다(2,028줄).

## 결과

### AUC

| 세트 | 방식 | 원본 | 미세조정 |
|---|---|---|---|
| 평가셋 100장 | 한국어 | 0.897 | 0.899 |
| | 영어 | 0.902 | 0.907 |
| | 학습 형식 | 0.938 | 0.957 |
| 장소를 섞은 150장 | 한국어 | 0.738 | 0.762 |
| | 영어 | 0.728 | 0.745 |
| | 학습 형식 | 0.836 | 0.821 |

- **같은 질문끼리 보면 두 모델이 거의 같다.** 차이가 0.02 안팎이고, 150장의 학습 형식에서는
  원본이 더 높다
- **AUC 를 올린 것은 모델이 아니라 질문이다.** 학습 형식으로 물으면 원본도 0.738 에서 0.836 으로
  오른다
- 장소를 섞으면 어느 조합이든 0.1 넘게 내린다

연기 탐지의 90% 를 남기는 문턱을 따로 잡아 다시 셌다.

| 세트 | 거른 헛탐지 (연기 탐지 90% 를 남길 때) |
|---|---|
| 평가셋 100장 | 조합에 따라 38~43 / 47 |
| 장소를 섞은 150장 | 어느 조합이든 14~15 / 30 |

**AUC 는 올라도 거르는 수는 늘지 않는다.**

| 세트 | 종류 | 원본, 한국어 | 미세조정, 한국어 | 미세조정, 학습 형식 |

| 평가셋 100장 | 굴뚝연기 | 2/6 | 2/6 | 2/6 |

- 안개연무는 미세조정 모델의 학습 형식에서만 8개 중 3개를 걸렀다. 표본이 적다

### 처리 시간

| 방식 | 조각 하나 (중앙값) |
|---|---|
| 한국어, 영어 | 0.9초 |
| 학습 형식 | 1.7초 |

개발 노트북 GPU 값이다. 학습 형식은 질문이 길어 두 배쯤 걸린다.

## 정리

1. **검증기는 원본 그대로 둔다.** 미세조정 모델로 바꿔도 같은 질문에서는 차이가 없다
2. **직접 미세조정은 하지 않는다.** 산불 사진으로 학습한 공개 모델이 이 자리에서 차이를 내지
   못했다. 남은 헛탐지(굴뚝연기, 안개)는 "연기인가"를 더 잘 맞히는 것으로 풀리는 종류가 아니다
3. **질문 형식은 바꾸지 않는다.** 학습 형식으로 물으면 AUC 는 오르지만 거르는 수는 같고 시간은
   두 배다
4. 굴뚝연기는 건물 자료로 가린다(`docs/chimney_demo.md`, `docs/vlm_situation.md`). 안개는 한계로 둔다

## 한계

- 헛탐지가 평가셋 47개, 150장 30개로 적다. 0.02 차이에는 의미를 두기 어렵다
- 150장 중 117장은 탐지 모델 학습과 검증에 쓴 영상이다(`docs/vlm_situation.md`)
- 미세조정 모델은 사진 전체를 보도록 학습했는데 여기서는 잘라 낸 조각을 줬다. 그 모델에
  불리한 조건일 수 있다
- 평가셋은 연기 사진과 연기 아닌 사진의 촬영 장소가 갈려 있다. 150장으로 함께 본 이유다
- 학습 형식은 첫 항목의 확률만 읽었다. 11개 항목을 끝까지 생성했을 때의 답과 같다고 볼 수 없다
- 미세조정 모델이 내는 나머지 항목(화재 상태, 강도, 크기 등)은 재지 않았다. 우리 평가셋에는
  그 항목의 정답이 없다
- 3B 크기의 모델 둘만 봤다. 더 큰 모델은 재지 않았다
