# 오차 반경 등각 보정과 확신 점수 (선택적 예측)

시스템이 자기 판단을 얼마나 믿어야 하는지 두 방향으로 손봤다.

1. 오차 반경을 등각 예측(split conformal)으로 보정해, 실제 위치가 반경 안에 들어오는 비율(포함률)을
   보장한다
2. 규칙과 문턱 대신 확신 점수를 배워, 확실한 것부터 확정한다(선택적 예측). 위치(용도 확정)와
   연기(탐지, 검증기) 둘 다 본다

담당: 이예진 / 상태: 측정 완료(11/22), 시뮬레이션과 기존 결과 파일로만 쟀다

## 데이터

- 위치 사례: `tools/verdict_coverage.py` 의 사례 만들기를 그대로 불러 썼다(강릉 시연 지역, 발화점 600곳,
  시뮬레이터 탐지 오차, 검증기 V2). 보정·학습용은 시드 7, 시험용은 기존 실험과 같은 시드 42 다.

## 1. 오차 반경 등각 보정

보정 사례에서 s = 실제 오차 / 계산한 반경 을 모으고, 그 ceil((n+1)(1-alpha)) 번째 값 q 를 반경에
곱한다(alpha = 0.1, 목표 포함률 90%). 보정 사례와 새 사례가 같은 분포면 분포를 가정하지 않고 포함률
90% 이상이 보장된다. 거리마다 따로 q 를 구하는 방식(거리별 보정)도 봤다.

보정 사례(잡음 1배)에서 q = 1.21, 거리별 q 는 200m 2.08, 300m 0.99, 400m 0.73, 600m 0.91, 800m 0.91 이다.

### 같은 잡음으로 보정했을 때

| 시험 | 방식 | 포함률 | 200m | 300m | 400m | 600m | 800m | 확정 | 확정 정확도 | 틀린 단정 |
|---|---|---|---|---|---|---|---|---|---|---|
| 잡음 1배 | 계산한 반경 (지금) | 84% | **56%** | 90% | 96% | 93% | 91% | 48% | 92.4% | 3.7% |
| | 보정 x1.21 | **90%** | 71% | 94% | 98% | 96% | 96% | 45% | 91.9% | 3.7% |
| | 거리별 보정 | 88% | **89%** | 90% | 87% | 89% | 88% | 43% | 95.0% | 2.2% |
| | 고정 50m | 61% | 74% | 88% | 77% | 36% | 18% | 48% | 92.7% | 3.5% |
| 잡음 2배 (2배로 보정, q=1.49) | 계산한 반경 (지금) | 71% | 50% | 75% | 81% | 75% | 82% | 49% | 89.8% | 5.0% |
| | 보정 x1.49 | 89% | 72% | 94% | 96% | 94% | 94% | 42% | 93.6% | 2.7% |
| | 거리별 보정 | **90%** | 90% | 89% | 94% | 90% | 87% | 38% | 94.8% | 2.0% |

- **보정하면 목표 포함률 90% 를 맞춘다.** 잡음 1배에서 84% → 90%, 잡음 2배에서 71% → 89~90% 다
- **지금 반경은 200m 에서 정답을 절반쯤(56%)만 담는다.** 가까운 거리에서는 탐지 밑동 오차가 반경
  공식보다 크다(거리별 q 가 2.08). 전체 q 하나로는 200m 가 71% 에 그치고, 거리별 보정을 해야 거리마다
  87~90% 로 고르게 맞는다
- 고정 50m 는 판정 성적(92.7%)은 지금 반경과 비슷하지만 포함률이 61%, 800m 에서 18% 다. 관제 화면에
  그린 원이 실제 위치를 담지 못한다. 계산한 반경을 쓰고, 그 반경을 보정해야 하는 이유다
- 반경이 커지면 확정이 조금 줄고 틀린 단정도 준다(거리별 보정 잡음 1배: 확정 48% → 43%, 틀린 단정
  3.7% → 2.2%). 확정 비율이 다르므로 판정 성적은 2번처럼 같은 확정 비율에서 견줘야 공정하다

### 보정과 실제 잡음이 다를 때 (한계)

| 보정에 쓴 잡음 | 시험 잡음 | 보정 x q | 거리별 보정 |
|---|---|---|---|
| 1배 | 2배 | 82% | 76% |
| 2배 | 1배 | 94% | 95% |

보장은 보정 사례가 실제와 같은 분포일 때만 성립한다. 실제 잡음이 보정 때보다 크면 다시 모자라고,
작으면 넉넉해진다. 그래서 실제 비행(11/24 촬영)에서 모은 오차로 보정하는 것이 다음 단계다.

## 2-1. 위치: 규칙 대신 확신 점수로 확정

지금 판정 규칙(`src/pipeline/verdict.py`)과 같은 정보(반경 안 1, 2순위 용도 비율, 용도지역 덮인 비율,
얕은 각 여부, 반경, 거리)로 "1순위 용도가 맞을 확률"을 로지스틱 회귀로 배웠다(보정용 사례 600개,
잡음 1배). 그리고 규칙과 같은 수만큼, 점수가 높은 사례부터 확정했다.

| 시험 | 방식 | 확정 | 확정 정확도 | 틀린 단정 [95%] |
|---|---|---|---|---|
| 잡음 1배 | 지금 규칙 | 48% | 92.4% | 3.7% [2.3, 5.3] |
| | 1순위 비율 순 | 48% | 92.7% | |
| | **확신 점수 순** | 48% | **94.8%** | **2.5% [1.2, 3.8]** |
| 잡음 2배 | 지금 규칙 | 49% | 89.8% | 5.0% [3.3, 6.8] |
| | 1순위 비율 순 | 49% | 90.5% | |
| | **확신 점수 순** | 49% | **94.2%** | **2.8% [1.5, 4.2]** |

차이(확신 점수 - 규칙)의 95% 구간은 잡음 1배 -2.3 ~ -0.3%p, 잡음 2배 -3.5 ~ -1.0%p 로 둘 다 0 을 걸치지
않는다. 구간은 시험 사례를 2000번 다시 뽑아 냈다(모델은 고정).

- **같은 양을 확정해도 틀린 단정이 준다.** 잡음 1배로만 배웠는데 잡음 2배에서 차이가 더 크다
- 점수가 있으면 확정 비율을 고를 수 있다. 잡음 1배에서 확정 40% 면 정확도 98.8%(틀린 단정 0.5%),
  60% 면 93.9%(3.7%) 다. 규칙은 이 비율을 바꿀 수 없다
- 계수(표준화)는 1순위 비율 +2.01, 반경(log) +0.47, 2순위 비율 +0.44, 얕은 각 -0.39 순이다. 규칙이 쓰던
  정보를 가중치로 다시 정리한 것이라 설명하기 쉽다
- 점수의 보정도 괜찮다(ECE 0.040, 잡음 2배 0.050). 관제 화면에 "맞을 확률"로 보여 줄 수 있다

## 2-2. 연기: 탐지 점수와 검증기 점수 합치기

| 세트 | 점수 | AUC [95%] | AURC [95%] | ECE |
|---|---|---|---|---|
| 평가셋 (5겹 교차검증) | 탐지 conf | 0.761 | 0.111 | 0.328 |
| | 검증기 p_smoke (지금) | 0.916 [0.804, 0.993] | 0.099 [0.029, 0.188] | 0.070 |
| | p_smoke 보정 (Platt) | 0.907 | 0.113 | **0.029** |
| | **합침** | **0.928** [0.836, 0.991] | **0.071** [0.026, 0.129] | 0.051 |
| 150장 (5겹 교차검증) | 검증기 p_smoke (지금) | 0.738 [0.600, 0.867] | 0.121 | 0.107 |
| | **합침** | **0.804** [0.724, 0.893] | **0.065** | 0.033 |
| 평가셋으로 맞추고 150장에 적용 | 검증기 p_smoke (지금) | 0.738 | 0.121 | 0.107 |
| | **합침** | **0.803** [0.704, 0.900] | **0.066** | 0.131 |

합침 = logit(탐지 conf), logit(p_smoke) 두 개로 로지스틱 회귀. 구간은 사진 단위 부트스트랩 2000번이다.
AURC 는 점수 높은 탐지부터 남길 때 남긴 것 중 헛탐지 비율을 평균한 값이다(작을수록 좋다).

- **두 점수를 합치면 순위가 나아진다.** 차이 구간이 0 을 걸치지 않는 것은 평가셋으로 맞추고 150장에
  적용한 경우(AUC +0.018 ~ +0.118, AURC -0.101 ~ -0.006)다. 나머지는 나아지는 쪽이지만 0 을 걸친다
- 지금 문턱(0.7)과 같은 수를 남기면 이득이 거의 없다(평가셋 위험 3.8% → 4.5%, 150장 11.7% → 10.2%).
  이득은 더 적게 남길 때 나온다
- **점수 보정은 세트 안에서만 된다.** 같은 세트로 보정하면 ECE 가 0.070 → 0.029 로 줄지만, 다른 세트로
  옮기면 0.131 ~ 0.171 로 나빠진다. 장소가 바뀌면 다시 보정해야 한다. 1번의 한계와 같은 이야기다

## 정리

- 오차 반경은 등각 보정으로 포함률 90% 를 맞출 수 있다. 지금 반경은 200m 에서 특히 작다
- 규칙 대신 확신 점수로 확정하면, 같은 확정 비율에서 틀린 단정이 3.7% → 2.5%(잡음 2배 5.0% → 2.8%)로
  준다
- 연기 쪽은 탐지 점수와 검증기 점수를 합치면 순위가 나아지지만, 지금 문턱 근처에서는 차이가 작다
- 모두 시뮬레이션(강릉 한 지역)과 기존 평가 결과로 쟀다. 보정은 실제와 같은 분포의 보정 데이터가
  있어야 성립하므로, 실제 비행 오차로 다시 보정해야 한다

## 아직 안 한 것

- 파이프라인(`src/pipeline`)과 대시보드에는 아직 넣지 않았다. 넣으려면 판정 규칙 대신 확신 점수와
  문턱을 쓰고, 반경에 거리별 q 를 곱하면 된다
- 위치 확신 점수와 연기 확신 점수를 곱해 알람 하나의 확신으로 쓰는 것은 아직 재지 않았다. 두 점수를
  잰 데이터가 서로 다르다(시뮬레이션 대 실제 사진)
