# 시연 지역 용도지역과 DEM 준비 (WBS 3.2)

시연 지역 모래고개입구 주변의 용도지역 폴리곤과 DEM을 정리한다. 지리 조회(3.4)와 임계값 모의 실험(3.5), 가상 배치 위치 재확인(3.7)에 쓴다.

담당: 이수진 / 상태: 검토 요청

## 범위

| 항목 | 값 |
|---|---|
| 범위 (경도·위도) | 128.880, 37.712 ~ 128.932, 37.762 (3.7 가상 배치에 쓴 범위와 같음) |
| 범위 (EPSG:5179) | x 약 1,121,554~1,126,219 / y 약 1,968,943~1,974,559 |
| 크기 | 가로 약 4.6km, 세로 약 5.6km, 면적 25.43km² |
| 중심 참고 | 모래고개입구 37.736790, 128.906239 (`data_select.md`의 GPS 중앙값)가 범위 거의 가운데 |
| 좌표계 | 저장 파일은 EPSG:5179 (DEM과 같음). 원본은 EPSG:4326도 함께 저장 |

## 용도지역

### 레이어 4종을 모두 받아야 함

V-World에서 용도지역은 레이어 4개로 나뉘어 있다. `LT_C_UQ111`에는 도시지역만 들어 있다.

| 레이어 | 내용 | 범위 안 폴리곤 수 |
|---|---|---|
| LT_C_UQ111 | 도시지역 (주거, 상업, 녹지 등) | 120 |
| LT_C_UQ112 | 관리지역 | 137 |
| LT_C_UQ113 | 농림지역 | 28 |
| LT_C_UQ114 | 자연환경보전지역 | 0 |

- 기존에 `LT_C_UQ111`만 받았을 때 도시지역 8종만 나오고 산간 쪽 약 26%가 비었던 이유가 이것이다
- 4종을 합치면 범위 전체(100.0%)가 용도지역으로 덮인다. 빈 곳 없음

### 받는 방법

- 코드: `tools/fetch_landuse.py` (V-World 2D데이터 API GetFeature, 파이썬 기본 기능만 사용, 추가 설치 없음)
- 실행:
  ```
  export VWORLD_KEY=발급받은키
  python3 tools/fetch_landuse.py <출력 폴더>
  ```
  범위를 바꾸려면 뒤에 `최소경도 최소위도 최대경도 최대위도`를 붙인다
- 인증키는 코드와 문서에 적지 않고 환경 변수로만 넣는다

### 출력 파일 (저장소에는 올리지 않음)

| 파일 | 내용 |
|---|---|
| `landuse_4326.geojson` | 받은 폴리곤 원본 (위도·경도, 범위 밖까지 이어진 폴리곤 포함) |
| `landuse_5179.geojson` | 범위로 자른 폴리곤 (EPSG:5179) |
| `landuse_summary.csv` | 용도지역별 면적과 비율 |

- 각 폴리곤에 `layer`(레이어 코드)와 `kind`(도시·관리·농림·자연환경보전)를 붙였다
- 용도지역 이름은 속성 `uname`에 있다. 그 밖에 `dyear`(고시 연도), `sido_name`, `sigg_name` 등이 있다

## DEM

| 항목 | 값 |
|---|---|
| 사용 도엽 | 구정(37808) + 그 북쪽 도엽(37804). 둘 다 90m 격자, EPSG:5179, 이미 확보 |
| 범위 포함 여부 | 범위 대부분은 37808 안. 북쪽 약 1.3km(y 1,973,250 이상)는 37804에 있음. 두 장을 합치면 범위 전체가 들어감 |
| 모래고개입구 지면 높이 | 약 13m |
| 모래고개입구 주변 3×3칸(270m) 경사 | 약 1.4° (거의 평지) |

- 새로 받을 DEM은 없다
- 조회할 때 지점이 어느 도엽에 있는지 보고 해당 도엽 값을 읽어야 한다

## 남은 것

- 건물 데이터(`buildings_in_radius`용)를 받을지 정하기. 제안서에는 V-World 건물 위치와 용도도 쓰기로 되어 있음
- 1,000곳 모의 실험(3.5)에서 "임계값을 정한 지역과 다른 지역"에 쓸 두 번째 지역 정하기
- 3.7 가상 배치 36곳을 4종 용도지역 기준으로 다시 확인하기
- 고시 연도(`dyear`)가 폴리곤마다 다르다(예: 2019, 2020). 이후 바뀐 고시와 다를 수 있음
