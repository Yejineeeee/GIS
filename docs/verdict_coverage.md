# 같은 확정 비율에서 견주기 (핵심 주장 보강)

반경 판정(D+)은 한 점 조회보다 틀린 단정을 18.3% 에서 3.7% 로 줄이지만, 확정도 100% 에서 48% 로
준다(`docs/verdict_compare.md`). 확정을 줄이기만 해도 틀린 단정은 준다. 그래서 두 가지를 쟀다.

1. 한 점 조회도 같은 비율만 골라 확정하면 정확도가 얼마인가
2. 반경을 사례마다 계산하지 않고 고정해도 같은 효과가 나는가

담당: 이예진 / 상태: 측정 완료(11/18)

## 방법

`tools/verdict_coverage.py`. 사례(발화점 600곳, 시뮬레이터 탐지 오차, 자세 잡음, 시드 42, 검증기 V2)는
`tools/verdict_compare.py` 와 같은 순서로 만든다. 반경 1배의 결과(확정 48%, 확정 정확도 92.4%,
틀린 단정 3.7%)가 기존 문서와 같게 나왔다.

```
python tools/verdict_coverage.py <landuse_5179.geojson> --out runs/verdict_coverage
```

한 점 조회의 답은 그대로 두고, 무엇을 확정할지만 세 가지로 골랐다.

| 기준선 | 고르는 법 |
|---|---|
| 무작위 | 아무거나 같은 비율 |
| 가까운 것부터 | 드론과 발화점의 거리가 짧은 사례부터 |
| 반경이 작은 것부터 | D+ 오차 반경이 작은 사례부터. 반경 판정과 같은 정보를 쓰되 반경 안의 용도를 보지 않는다 |

반경 판정의 확정 비율은 반경에 0.5~2배를 곱해 바꿨다. 고정 반경은 10~150m 로 두고 같은 판정 규칙
(`src/pipeline/verdict.py`)을 썼다.

## 1. 같은 확정 비율에서 한 점 조회와 견주면

확정한 것 중 맞은 비율이다.

| 반경 판정 | 확정 비율 | 반경 판정 | 가까운 것부터 | 반경이 작은 것부터 | 무작위 |
|---|---|---|---|---|---|
| 반경 x0.5 | 58% | 87.4% | 86.0% | 86.0% | 81.7% |
| 반경 x0.75 | 53% | 90.6% | 85.9% | 85.9% | 81.7% |
| **반경 x1 (지금)** | **48%** | **92.4%** | 85.8% | 85.5% | 81.7% |
| 반경 x1.5 | 40% | 93.8% | 87.2% | 87.2% | 81.7% |
| 반경 x2 | 35% | 95.7% | 85.6% | 86.1% | 81.7% |

- **같은 48% 를 확정해도 반경 판정이 7%p 정확하다.** 반경 판정 92.4%, 가장 강한 기준선(반경이 작은
  것부터) 85.5% 다
- 기준선은 확정을 줄여도 정확도가 85~87% 에서 멈춘다. 가까운 사례만 골라도 한 점 조회는 틀린다.
  탐지가 밑동을 잘못 짚거나 발화점이 용도 경계 가까이 있으면 거리와 상관없이 틀리기 때문이다
- 그래서 반경 판정의 효과는 기권을 많이 해서가 아니라, 반경 안에 용도가 섞였는지를 보고 기권할
  곳을 고르기 때문이다

## 2. 반경을 고정해도 되는가

| 판정에 쓴 반경 | 확정 비율 | 확정 정확도 | 틀린 단정 |
|---|---|---|---|
| 고정 10m | 60% | 86.7% | 8.0% |
| 고정 25m | 60% | 86.7% | 8.0% |
| **고정 50m** | **48%** | **92.7%** | **3.5%** |
| 고정 75m | 41% | 95.5% | 1.8% |
| 고정 100m | 34% | 97.6% | 0.8% |
| 계산한 반경 x1 (지금) | 48% | 92.4% | 3.7% |
| 계산한 반경 x1.5 | 40% | 93.8% | 2.5% |
| 계산한 반경 x2 | 35% | 95.7% | 1.5% |

- **이 실험에서는 고정 반경이 계산한 반경만큼, 또는 조금 더 낫다.** 같은 확정 비율에서 고정 50m 는
  92.7%, 계산한 반경은 92.4% 다. 확정 비율 35~41% 에서는 고정 반경이 2%p 쯤 높다
- 200~400m 만 봐도 같다. 고정 50m 는 확정 75%, 정확도 93.1%, 계산한 반경은 확정 75%, 92.4% 다.
  이 거리에서 계산한 반경의 중앙값이 53m 라 고정 50m 와 크기가 비슷하다
- 600~800m 는 어느 방식이든 거의 다 미확정이다. 217곳 중 216곳이 내려다보는 각이 얕아 판정 규칙이
  미확정으로 돌린다. 반경 크기와 상관없다
- 자세 오차 항이 없는 반경(D, 8.2%)이 나빴던 것은 반경이 10~25m 로 작았기 때문이다. 고정 10m, 25m
  (8.0%)와 같다

정리하면, 판정의 질을 정하는 것은 반경 공식의 세부가 아니라 **반경이 50m 안팎으로 충분히 큰지**와
**얕은 각을 미확정으로 돌리는 규칙**이다. 이 시뮬레이션의 거리(200~800m), 고도(120m)에서는 계산한
반경이 고정 50m 보다 판정을 더 좋게 만들지 못했다.

계산한 반경을 쓰는 이유는 판정이 아닌 다른 데 있다.

- 반경이 실제 오차를 담는다(포함률 84%). 고정 50m 는 600m 에서 오차를 담지 못한다. 관제 화면의
  원이 거짓말을 하지 않게 하는 것이 반경 공식의 몫이다
- 드론이 더 높거나 가까이 날면 알맞은 고정값이 달라진다. 계산한 반경은 따라 바뀐다. 이 실험은
  고도 120m 하나라 이 장점을 보여 주지 못했다

## 정리

- 핵심 주장은 같은 확정 비율에서도 성립한다. 48% 를 확정할 때 반경 판정 92.4%, 한 점 조회는 어떻게
  골라도 85~86% 다
- 다만 "자세 오차 항을 넣은 반경 공식이 판정을 좋게 한다"고는 말하지 않는다. 같은 크기의 고정 반경과
  차이가 없었다. 반경 공식은 오차 원을 정직하게 그리는 데 쓴다고 말한다
