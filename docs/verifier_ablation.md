# 탐지기 단독과 VLM 검증 비교, 헛탐지 유형

VLM 검증기가 실제로 무엇을 더하는지, 어떤 헛탐지를 거르고 어떤 것을 못 거르는지 정리했다.
새로 모델을 돌리지 않고 기존 결과 파일만 다시 셌다.

담당: 이예진 / 상태: 정리 완료(11/26)

## 데이터

| 세트 | 파일 | 탐지 | 연기 | 헛탐지 |
|---|---|---|---|---|
| 평가셋 (v2, 100장) | `results/verify_margin_eval.jsonl` | 177 | 131 | 46 |
| 장소를 섞은 150장 | `results/verify_margin_mix150.jsonl` | 165 | 135 | 30 |

- 탐지는 YOLO11n-seg(운영 문턱 0.10)가 낸 것이다. `smoke` 는 탐지가 연기 라벨과 겹치는지, `saved` 는
  지금 검증기(V2)의 P(예)다
- 헛탐지 유형은 사진 파일 이름의 분류(굴뚝연기, 안개연무)와 "연기 사진인데 연기 라벨과 겹치지 않는 탐지"로
  나눴다. 연기 사진 속 헛탐지를 밭, 맨땅처럼 더 잘게 나누는 것은 사진을 직접 봐야 해서 하지 않았다
- 발표 자료의 "연기 126개 중 119개, 헛탐지 47개 중 41개"는 평가셋 v1(탐지 173개, `docs/vlm_base_pick.md`)
  값이다. 여기 숫자는 v2 라서 조금 다르다

## 탐지기 단독 vs + VLM 검증 (문턱 0.7)

| 세트 | 방식 | 남긴 탐지 | 정밀도 | 재현율 |
|---|---|---|---|---|
| 평가셋 | 탐지기 단독 | 177 | 74.0% | 131/131 (100%) |
| | + VLM 검증 | 132 | **96.2%** | 127/131 (97%) |
| 150장 | 탐지기 단독 | 165 | 81.8% | 135/135 (100%) |
| | + VLM 검증 | 137 | **88.3%** | 121/135 (90%) |

정밀도는 남긴 탐지 중 연기 비율, 재현율은 연기 탐지 중 남긴 비율이다(탐지기 단독은 정의상 100%).

사진 단위(평가셋)로 보면 다음과 같다.

| | 탐지기 단독 | + VLM 검증 |
|---|---|---|
| 연기 없는 사진에서 알람 | 5장 | 3장 |
| 연기 사진에서 헛탐지가 같이 남은 사진 | 22장 | 1장 |
| 검증기 때문에 연기를 하나도 못 남긴 사진 | - | 1장 |

- **연기 사진 속 엉뚱한 곳을 잡은 헛탐지는 거의 다 거른다.** 위치를 계산할 탐지가 헛탐지인 사진이 22장에서
  1장으로 준다. 위치 판정에는 이 효과가 가장 크다
- **대가는 연기 탐지 일부를 버리는 것이다.** 평가셋 4개(3%), 150장 14개(10%). 처음 보는 장소에서 더 많이 버린다

## 헛탐지 유형별로 거른 비율 (문턱 0.7)

| 유형 | 평가셋 | 150장 |
|---|---|---|
| 연기 사진 속 다른 곳 | **39/40** | **11/13** |
| 굴뚝연기 | 2/6 | 3/9 |
| 안개연무 | - | **0/8** |

- **VLM 이 잘 거르는 것은 "연기가 아닌 것"이다.** 밭, 맨땅처럼 연기처럼 보이지 않는 곳은 "연기가 있는가"
  질문에 아니라고 답한다
- **못 거르는 것은 "연기처럼 보이는 진짜 다른 것"이다.** 굴뚝연기는 실제 연기이고, 안개연무는 연기와 모양이
  비슷하다. "이 사진에 연기가 있는가"로는 구분할 수 없다. 굴뚝은 건물 정보로 따로 구분하고
  (`docs/chimney_demo.md`), 안개연무는 지금 막을 방법이 없다
- 구름 사진에서는 탐지기가 아무것도 잡지 않아 검증할 대상이 없었다

## 버린 연기를 어떻게 다룰지

평가셋에서 검증기가 버린 연기 탐지 4개는 P(예)가 0.38, 0.45, 0.52, 0.59 로 모두 문턱 바로 아래였다.
그래서 점수를 셋으로 나눠 봤다: 0.7 이상 "연기", 0.35 ~ 0.7 "확인 필요", 0.35 미만 "헛탐지".

| 세트 | 방식 | 연기로 남김 | 확인 필요 | 버림 |
|---|---|---|---|---|
| 평가셋 | 둘로 나눔 (0.7) | 연기 127, 헛탐지 5 | - | 연기 **4**, 헛탐지 41 |
| | 셋으로 나눔 | 연기 127, 헛탐지 5 | 연기 4, 헛탐지 13 | 연기 **0**, 헛탐지 28 |
| 150장 | 둘로 나눔 (0.7) | 연기 121, 헛탐지 16 | - | 연기 **14**, 헛탐지 14 |
| | 셋으로 나눔 | 연기 121, 헛탐지 16 | 연기 5, 헛탐지 3 | 연기 **9**, 헛탐지 11 |

- 셋으로 나누면 버리는 연기가 평가셋 4 → 0, 150장 14 → 9 로 준다. 대신 관제사가 볼 "확인 필요"가
  평가셋 17개, 150장 8개 생긴다
- **0.35 는 평가셋을 보고 고른 값이라 평가셋 결과는 낙관적이다.** 장소가 다른 150장에서는 여전히 9개를 버린다.
  검증기 점수가 장소에 따라 달라지는 것(`docs/uncertainty_calibration.md` 2-2)과 같은 이야기다
- 위치 판정의 확정, 모호, 미확정과 같은 방식이라 "확신할 수 없으면 단정하지 않는다"를 연기 판정에도 쓸 수 있다

지금 파이프라인은 검증기가 아니라고 해도 알람을 지우지 않고 "헛탐지 가능성"으로 표시한다(`docs/pipeline.md`).
그래서 위 "버림"은 실제로는 알람이 사라지는 것이 아니라, 위치 계산에 쓸 탐지에서 빠지는 것이다.

## 정리

- VLM 검증은 정밀도를 평가셋 74% → 96%, 150장 82% → 88% 로 올린다. 위치를 계산할 탐지가 헛탐지인 사진이
  22장 → 1장으로 준다
- 잘 거르는 것은 연기 사진 속 엉뚱한 곳(39/40), 못 거르는 것은 굴뚝연기(2/6)와 안개연무(0/8)다
- 연기 탐지를 3~10% 버린다. 점수를 셋으로 나눠 중간을 "확인 필요"로 두면 버리는 연기가 준다(150장 14 → 9)
- 한계: 헛탐지 46개, 30개로 적고, 확인 필요 구간은 같은 데이터로 골랐다. 새 장소의 사진으로 다시 확인해야 한다
