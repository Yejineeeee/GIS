# 글 전용 LLM 으로 설명 쓰기 (방식 i 비교)

제안서는 설명 문장을 LLM 으로 쓰게 했다. 우리는 VLM 이 직접 쓰는 방식 (i) 이 판정을 자주
어겨서 문장을 규칙과 템플릿으로 바꿨다(`docs/generation_methods.md`). 여기서는 "사진을
보지 않는 글 전용 LLM 이면 판정을 따르는가"를 쟀다. 글 전용 LLM 은 알람 값만 받으므로
현장 기기가 아니라 관제 서버에서 돌려도 되는 구조다.

담당: 이예진 / 상태: 측정 완료(11/25)

## 방법

`tools/run_text_llm.py`. 방식 (i) 과 바꾼 것은 두 가지다.

- 모델: Qwen2.5-VL-3B-Instruct → Qwen2.5-3B-Instruct (같은 계열, 같은 크기의 글 전용)
- 입력: 사진을 빼고, 조건 D 프롬프트 첫 줄의 "사진" 표시를 지웠다

나머지는 같다. 평가셋 100건(`results/eval_facts.jsonl`), 조건 D 프롬프트(v2), 4bit nf4,
bf16, 그리디, repetition_penalty 1.15, 최대 140토큰. 채점은 `tools/score_descriptions.py`
그대로다. 결과는 `results/eval_method_i_text.jsonl` 이다.

```
TEXT_LLM=<모델 폴더> python tools/run_text_llm.py results/eval_facts.jsonl results/eval_method_i_text.jsonl
```

## 결과

연기가 있는 70장 기준 판정 준수다.

| 모델 | 판정 준수 | 확정 | 모호 | 미확정 | 과신률 | 장당 초 |
|---|---|---|---|---|---|---|
| VLM (방식 i) | 51% | 32/41 | 4/15 | 0/14 | 40% | 13.6 |
| 글 전용 LLM | 27% | 17/41 | 2/15 | 0/14 | 51% | 4.7 |
| 띄어쓰기 허용 시 VLM | 54% | 34/41 | 4/15 | 0/14 | | |
| 띄어쓰기 허용 시 글 전용 LLM | 61% | 41/41 | 2/15 | 0/14 | | |
| 규칙과 템플릿 (방식 iii) | 100% | | | | 0% | 6.2 |

채점기는 용도 이름을 글자 그대로 찾는다. 글 전용 LLM 은 "자연녹지지역"을 "자연 녹지
지역"처럼 띄어 쓴 경우가 많아 확정에서 24건이 떨어졌다. 띄어쓰기만 허용해 다시 세면
확정은 41/41 로 모두 맞는다. 위 표의 아래 두 줄이 그 값이고, 채점기는 바꾸지 않았다.

## 알게 된 것

- **불확실한 판정에서는 사진 유무와 상관없이 거의 다 어긴다.** 모호와 미확정 29장 중 VLM
  은 4장, 글 전용 LLM 은 2장만 지켰다. 미확정은 둘 다 0/14 다. 용도 이름을 쓰지 말라고
  지시해도 "제1종일반주거지역에서 관측되며"처럼 단정한다.
- **확정은 글 전용 LLM 이 잘 따른다.** 띄어쓰기를 허용하면 41/41 이다. 주어진 이름을
  옮겨 쓰기만 하면 되는 경우다.
- 그래서 문제는 사진을 보느냐가 아니라, 모델이 "모른다"를 문장으로 지키지 못하는 데 있다.
  판정이 필요한 곳이 바로 모호와 미확정이므로, 문장을 모델에 맡기면 판정의 의미가 사라진다.
- 글 전용 LLM 은 장당 4.7초로 VLM 보다 빠르다. 사진을 읽지 않기 때문이다.

## 상용 LLM (OpenAI API, 11/25 추가)

관제 서버에서 상용 모델을 쓰는 경우를 쟀다. `tools/run_api_llm.py`. 입력은 글 전용 LLM 과
같은 프롬프트다. 사진, 파일 이름, 좌표는 보내지 않았다. 온도 0, 최대 2000토큰.

| 모델 | 판정 준수 | 확정 | 모호 | 미확정 | 과신률 | 요소 포함 | 장당 초 |
|---|---|---|---|---|---|---|---|
| gpt-6.2-sol | 100% | 41/41 | 15/15 | 14/14 | 2% | 54% | 2.0 |
| gpt-6.2-astra | 100% | 41/41 | 15/15 | 14/14 | 0% | 54% | 2.7 |

결과는 `results/eval_method_i_gpt-6.2-sol.jsonl`, `results/eval_method_i_gpt-6.2-astra.jsonl`.
sol 의 과신 1건은 "두 곳 중 한 곳으로 보이나 어느 쪽인지 확실하지 않다"는 문장으로, 유보
표현은 있으나 채점 규칙에 걸렸다.

- **큰 상용 모델은 판정을 모두 지킨다.** 미확정도 14/14 다. 3B 모델(VLM, 글 전용)이 못 지킨
  것은 모델 크기 문제이고, 문장을 모델이 쓰는 방식 자체가 안 되는 것은 아니다.
- 그래서 규칙과 템플릿을 고른 이유는 정확도만이 아니다. 같은 100% 를 인터넷, 호출 비용,
  외부로 위치 정보를 보내는 일 없이 현장 기기에서 바로 낸다. 현장 기기에 들어가는 크기의
  모델은 미확정을 지키지 못했다.
- 상용 모델의 요소 포함은 54% 로 VLM 직접 작성(65%)보다 낮다. 사진을 보지 않아 "무엇이
  보이는가"를 탐지 값 이상으로 쓰지 못한다.

## 한계

- 로컬 모델은 같은 계열 3B 한 모델만 쟀다. 7B 급 로컬 모델이나 한국어 모델(EXAONE 등)은
  재지 않았다.
- 상용 모델은 100건, 한 번씩만 돌렸다. 모델 버전이 바뀌면 결과가 달라질 수 있다.
- 과신률은 채점기 그대로다. 띄어 쓴 용도 이름은 과신으로 세지 않아 글 전용 LLM 의 과신률이
  조금 낮게 잡혔을 수 있다.
