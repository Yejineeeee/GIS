# 설명 평가 기준

경량 VLM이 만든 상황 설명을 채점하는 기준이다. 입력 조건 네 가지를 같은 이미지에
적용하고 같은 기준으로 채점해, 지리 정보와 판정을 넣었을 때 설명이 어떻게 달라지는지
본다. 채점 기준이 흔들리면 결과를 다시 만들어야 하므로 채점 전에 확정한다.

담당: 이예진 / 상태: 초안

## 무엇을 비교하나

| 조건 | 모델에 주는 것 |
|---|---|
| A | 이미지만 |
| B | 이미지 + 탐지 결과 |
| C | B + 오차 반경 안 1순위 용도 |
| D | C + 확정, 모호, 미확정 판정과 오차 반경 |

20장 × 모델 2개 × 조건 4개 = 160건을 채점한다.

## 지표

### 1. 환각률

입력에서 확인되지 않는 내용을 사실로 쓴 설명의 비율이다.

- 분모: 형식을 지킨 설명 건수
- 분자: 환각 문장이 하나 이상 있는 설명 건수

환각 문장은 세 가지로 나눠 센다. 하나라도 있으면 환각 건이다.

| 유형 | 내용 | 예 |
|---|---|---|
| 잘못 봄 | 이미지에 있는 것을 다른 것으로 말함 | 연기를 불꽃이라고 함 |
| 없는 것 | 이미지에도 입력에도 없는 것을 있다고 함 | 비가 내린다, 표시물이 있다 |
| 근거 없는 추론 | 입력에 없는 원인, 수치, 지명을 단정 | 입산자 실화로 보인다, 풍속 5m |

환각으로 보지 않는 것
- 입력 JSON에 있는 값을 그대로 옮긴 경우
- 이미지에서 눈으로 확인되는 것을 적은 경우

보조 지표로 유형별 건수와 설명 1건당 환각 문장 수도 센다.

### 2. 과신률

위치가 확실하지 않은데도 단정해서 말한 비율이다. 이 연구가 줄이려는 값이다.

- 분모: 위치 판정이 모호 또는 미확정인 건수
- 분자: 그중 단정 표현을 쓴 건수

조건 A와 B에는 판정이 입력으로 들어가지 않는다. 채점할 때는 같은 이미지에 대해
계산된 판정을 기준으로 분모를 잡는다. 모델이 판정을 못 받았다는 것은 변명이 되지
않고, 그 차이를 보는 것이 실험의 목적이다.

### 3. 필수 요소 포함률

설명에 들어가야 하는 네 가지가 몇 개 들어갔는지 센다. 건별로 0에서 4까지 매기고
평균을 4로 나눈다.

| 요소 | 인정 기준 |
|---|---|
| 무엇 | 정답 클래스와 일치하는 이름을 씀. 연기를 화염이라고 하면 인정하지 않는다 |
| 어디 | 용도지역 이름 또는 좌표를 명시 |
| 위험 대상 | 산림, 주거지, 건물, 도로, 농경지, 시설 중 하나를 명시. 땅, 토양, 지면, 바닥은 인정하지 않는다 |
| 불확실성 | 오차 반경 수치 또는 유보 표현을 명시 |

### 3-1. 회피 건수

요소가 1개 이하인 설명은 회피로 센다. 틀린 말을 안 해서 환각률이 좋아지는 경우를
가려내기 위한 것이다.

### 4. 형식 준수율

지정한 JSON 형식으로 답한 비율이다. `description` 하나만 있는 객체로 파싱되면
준수로 본다. 코드 블록 기호가 붙어 있어도 안쪽이 파싱되면 준수로 본다.

형식을 안 지킨 건은 이 지표에만 넣고 나머지 세 지표의 분모에서 뺀다. 문장이
미완성이면 환각인지 판단할 수 없기 때문이다. 조건별로 몇 건을 뺐는지 결과 표에
같이 적는다.

## 단정 표현과 유보 표현

과신률 채점이 사람마다 달라지지 않도록 표현 목록을 먼저 고정한다. 목록에 없는
표현이 나오면 채점을 멈추고 셋이 합의해 목록에 추가한 뒤 그 시점까지 채점한 건을
다시 본다.

단정 표현
- `~이다`, `~에서 발생했다`, `~에 위치한다`, `~를 덮쳤다`, `확인되었다`, `~로 인해`

유보 표현
- `~로 추정된다`, `~일 가능성이 있다`, `~로 보인다`, `확인이 필요하다`,
  `오차 반경 N미터 안에`, `~와 ~ 중 하나로 보인다`

판정이 확정인데 유보 표현만 쓴 경우는 과신이 아니다. 대신 요소 포함률에서
`어디`가 빠졌는지 따로 본다.

## 채점 방법

1. 160건을 조건과 모델 정보를 지운 채 섞어서 채점표에 넣는다. 채점자는 그 설명이
   어느 조건에서 나왔는지 모르는 상태로 채점한다.
2. 두 사람이 각각 채점한다.
3. 두 사람의 결과가 다른 건만 세 번째 사람이 보고 정한다.
4. 채점자 사이 일치율을 기록한다. 0.6 미만이면 기준 문장을 고치고 다시 채점한다.

`tools/make_score_sheet.py`로 채점표를 만들면 조건 열이 가려진 상태로 나온다.

## 보고할 값

조건별로 아래를 표로 낸다. 결과가 기대와 달라도 그대로 적는다.

| 조건 | 환각률 | 회피 건수 | 요소 포함률 | 과신률 | 형식 준수율 | 제외 건수 |
|---|---|---|---|---|---|---|
| A | | | | | | |
| B | | | | | | |
| C | | | | | | |
| D | | | | | | |

**환각률을 단독으로 보고하지 않는다.** 조건 D는 미확정일 때 용도 이름을 쓰지 말라고
지시하므로, 지시를 따르면 말수가 줄고 환각률이 자동으로 내려간다. 말을 덜 해서
내려간 것과 제대로 판단해서 내려간 것을 구분해야 한다.

읽는 규칙
- 환각률이 내려가고 요소 포함률이 유지되면 개선이다.
- 환각률이 내려갔지만 요소 포함률도 내려갔으면 개선이 아니다. 회피다. 그렇게 적는다.
- 회피 건수가 조건 D에서 크게 늘면 프롬프트의 지시가 지나치게 강한 것이다.
